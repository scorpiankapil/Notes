# Pivoting

Pivoting is technique used during penetration testing to move laterally within a compromised network. 
It allows attackers or penetration testers to use a compromised systems as a bridge or gateway to access other systems, networks, or resources that would be inaccessible.

- Access internal networks
- Bypass firewalls
- Reach hidden services
- Enumerate internal hosts
- Move laterally through a network
- Access sensitive servers (e.g., databases, domain controllers)
