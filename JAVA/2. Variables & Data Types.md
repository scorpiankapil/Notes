## First Program in Java

```
public class Main{  
    public static void main(String[] args){  
        System.out.println("Hello World!");  
    }  
}
```

**Everything is java is written in classes**

#### What is class?

A Class is a user defined blueprint or template used to create objects. It defined the variables and methods that object of that class will have.

#### What is method?

A method is a block of code that performs a specific task and can be reused whenever needed.


- **public static void main(String[] args)**

|Keyword|Meaning|
|---|---|
|`public`|The method can be accessed from anywhere. JVM must be able to access it.|
|`static`|The method belongs to the class, not to an object. JVM can call it without creating an object.|
|`void`|The method does not return any value.|
|`main`|Special method name recognized by the JVM as the starting point of execution.|
|`String[] args`|An array of strings used to receive command-line arguments.|

- **System.out.println("Hello World!");**

|Part|Meaning|Purpose|
|---|---|---|
|`System`|A built-in Java class from `java.lang` package.|Provides access to system resources.|
|`out`|A static object of type `PrintStream` inside the `System` class.|Represents the standard output device (console/screen).|
|`println()`|A method of the `PrintStream` class.|Prints data and moves the cursor to the next line.|
|`"Hello World!"`|A String literal.|The text to be displayed on the screen.|

# Variables in Java

A variable is a reserved memory location used to store data values. The value stored in a variable can be changed during program execution.

```
Syntax: data_type variable_name = value;
```

```
int age = 21;
```

|Part|Description|
|---|---|
|`int`|Data type|
|`age`|Variable name|
|`21`|Value stored|
|Memory|A reserved memory location is allocated to store `21`|

#### What is keywords in java?

Keywords are reserved words in Java that have predefined meanings and cannot be used as identifiers (variable names, class names, method names, etc.).

# Data types in Java

A data type specifies the type of data that a variable can store and the amount of memory required to store it.

## Types of Data Types in Java

### 1. **Primitive Data Types**

Primitive data types are built-in or predefined data types used to store simple values such as numbers, characters, and boolean values.

**8 Primitive Data Types in Java**

|Data Type|Size|Range|Example|
|---|---|---|---|
|`byte`|1 Byte|-128 to 127|`byte age = 25;`|
|`short`|2 Bytes|-32,768 to 32,767|`short num = 1000;`|
|`int`|4 Bytes|-2³¹ to 2³¹-1|`int marks = 90;`|
|`long`|8 Bytes|-2⁶³ to 2⁶³-1|`long population = 100000L;`|
|`float`|4 Bytes|Decimal values|`float price = 99.5f;`|
|`double`|8 Bytes|Decimal values|`double salary = 50000.75;`|
|`char`|2 Bytes|Single character|`char grade = 'A';`|
|`boolean`|Logical|`true` or `false`|`boolean passed = true;`|
### 2. **Non-Primitive Data Types**

Non-Primitive Data Types are data types that store references (memory addresses) to objects rather than storing the actual values directly.

|Data Type|Example|
|---|---|
|String|`String name = "Kapil";`|
|Array|`int[] arr = {1,2,3};`|
|Class|`Student s = new Student();`|
|Interface|User-defined interface|
|Object|`Object obj = new Object();`|
