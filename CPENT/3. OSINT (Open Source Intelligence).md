# OSINT (Open Source Intelligence)

**OSINT (Open Source Intelligence)** is the process of **collecting information about a target from publicly available sources** without directly interacting with or attacking the target.

- **Open Source** → Publicly available information (not secret or hacked data).
- **Intelligence** → Useful information collected about the target.

## Finding the Domain and Subdomains of the Target

**Domain Enumeration** is the process of identifying the **main domain** and all its **subdomains** to understand the target's attack surface.

|**Term**|**Example**|**Description**|
|---|---|---|
|**Domain**|`example.com`|The main website or primary domain of an organization.|
|**Subdomain**|`mail.example.com`|A subdivision of the main domain used for a specific service.|

```
subfinder -d google.com
```

```
nmap --script dns-brute google.com
```
