# IFCONFIG (Interface Configuration)

**IFCONFIG (Interface Configuration)** is a Linux/UNIX command-line utility used to view, configure, enable, and disable network interfaces (network cards).

It is similar to the **IPCONFIG** command in Windows.

### Why Use IFCONFIG?

1. View IP address information.
2. View MAC address information.
3. Configure network interfaces.
4. Enable network cards.
5. Disable network cards.
6. Troubleshoot network connectivity issues.

# IFCONFIG Commands and Their Uses

| Command                                    | Use                                                                    |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| `ifconfig`                                 | Display information about active network interfaces                    |
| `ifconfig -a`                              | Display information about all network interfaces (active and inactive) |
| `ifconfig eth0`                            | Display details of a specific interface (eth0)                         |
| `ifconfig eth0 up`                         | Enable (activate) the network interface                                |
| `ifconfig eth0 down`                       | Disable (deactivate) the network interface                             |
| `ifconfig eth0 192.168.1.10`               | Assign an IP address to the interface                                  |
| `ifconfig eth0 netmask 255.255.255.0`      | Set the subnet mask for the interface                                  |
| `ifconfig eth0 broadcast 192.168.1.255`    | Set the broadcast address                                              |
| `ifconfig eth0 mtu 1500`                   | Set the MTU (Maximum Transmission Unit) size                           |
| `ifconfig eth0 hw ether 00:11:22:33:44:55` | Change the MAC address of the interface                                |
| `ifconfig eth0 promisc`                    | Enable promiscuous mode                                                |
| `ifconfig eth0 -promisc`                   | Disable promiscuous mode                                               |
| `ifconfig eth0 multicast`                  | Enable multicast support                                               |
| `ifconfig eth0 -multicast`                 | Disable multicast support                                              |
| `ifconfig lo`                              | Display loopback interface information                                 |
| `ifconfig lo up`                           | Enable the loopback interface                                          |
| `ifconfig lo down`                         | Disable the loopback interface                                         |
