# MTR (My Traceroute)

**MTR (My Traceroute)** is a network diagnostic tool that combines the features of **Ping** and **Traceroute** into a single tool.

It continuously tests the route to a destination and displays **hop-by-hop latency and packet loss** in real time.

- Ping      → Is destination reachable?
- Traceroute → Which path is used?
- MTR       → Which path + How healthy is the path?

```
mtr google.com
```

MTR discovered every router (hop) between your Linux machine and Google's server and continuously measured:

- Packet Loss
- Response Time (Latency)
- Network Stability
