# FTP (File Transfer Protocol)

**FTP (File Transfer Protocol)** is a TCP/IP protocol used to transfer files from one computer to another over a network.

It allows users to upload, download, and manage files on a remote server.

# How FTP Works

1. A user starts an FTP client and connects to an FTP server.
2. FTP uses **two TCP connections**:
    - **Port 21** → Control Connection (PI - Protocol Interpreter)
    - **Port 20** → Data Connection (DTP - Data Transfer Process)
3. The client connects to **TCP Port 21** on the FTP server.
4. The FTP server asks for a **username and password**.
5. The user enters valid credentials and logs in.
6. After login, the **control connection (Port 21)** remains active for sending commands.
7. When a file transfer is requested, FTP creates a **data connection (Port 20)**.
8. Commands travel through **Port 21**, while file data travels through **Port 20**.
9. This allows FTP to **send commands and transfer files simultaneously**.
10. The user can then:
    - View files (`dir` or `ls`)
    - Download files (`get`)
    - Upload files (`put`)
    - Change directories (`cd`)
11. FTP supports two transfer modes:
    - **ASCII (Text) Mode** → For text files
    - **Binary Mode** → For executables, images, videos, and other non-text files
12. After the transfer is complete, the data connection closes.
13. When the user exits FTP, the control connection also closes.
