# Telnet

**Telnet (Telecommunication Network)** is a network protocol used to remotely access and manage another computer or network device over a TCP/IP network.

It allows command-line access

It allows a user to log in to a remote system and execute commands as if they were physically sitting in front of it.

**Port Number: 23**

```
telnet 192.168.1.10 23
```

- **Telnet sends usernames, passwords, and data in plain text, which makes it insecure.** Therefore, **SSH (Port 22)** is preferred in modern networks.

# Working of Telnet

1. The user starts the Telnet client and enters the IP address of the remote device.
2. The Telnet client sends a connection request to the server on **TCP Port 23**.
3. The server accepts the connection request.
4. The server prompts the user for a **username and password**.
5. The user enters the login credentials.
6. The server verifies the credentials.
7. If authentication is successful, a remote command-line session is established.
8. The user executes commands on the remote system.
9. The server processes the commands and sends the results back to the user.
10. When the user logs out, the Telnet session is terminated.

# Troubleshooting with Telnet

Telnet can be used as a troubleshooting tool to test remote access, verify network services, and determine whether a problem is on the client side or server side.

- Helps access a remote server when other methods fail.
- Allows remote administration of servers.
- Helps determine whether a service is running.
- Helps identify whether a problem is client-side or server-side.
- Allows testing of specific TCP ports.
