# Route

A **Route** is the path that a data packet follows to travel from a source device to a destination device across a network.

Routes are stored in a **Routing Table**

```
PC A
  ↓
Router A
  ↓
Router B
  ↓
PC B
```

This path is called **The Route.**

# How Route Works

1. A packet needs to reach a destination network.
2. The computer checks its routing table.
3. The routing table contains the path (route) to the destination.
4. The packet is forwarded through the correct gateway/interface.
5. If no route exists, the packet is dropped.
