# HPING or HPING2

**Hping (or Hping2)** is an advanced network testing and troubleshooting tool similar to Ping, but instead of using **ICMP**, it uses **TCP packets** and allows you to customize them.

It is commonly used for **network troubleshooting, firewall testing, port scanning, and security testing**.

- Works even when ICMP (normal ping) is blocked.
- Send custom TCP packets.
- - Test network connectivity.
- Test specific ports on a target system.
- Check if a service is running.
- Troubleshoot firewall rules.

```
hping2 -c 3 -s 53 -p 80 -S 10.0.0.25
```

|Option|Meaning|
|---|---|
|`-c 3`|Send 3 packets|
|`-s 53`|Source Port = 53 (DNS Port)|
|`-p 80`|Destination Port = 80 (HTTP Port)|
|`-S`|Send a TCP SYN packet|
|`10.0.0.25`|Target IP Address|

# How Hping/Hping2 Works

1. Hping2 creates a **custom TCP packet** instead of an ICMP packet.
2. The user specifies the target IP address and port.
3. Hping2 sends the packet to the target system.
4. The target receives the packet and checks the destination port.
5. If the port is open, the target sends a response back.
6. If the port is closed, the target sends a different response or rejects the connection.
7. Hping2 measures:
    - Response time
    - Packet loss
    - Port status
8. The results are displayed on the screen.
9. Because Hping2 uses TCP, it can test specific services such as:
    - HTTP (Port 80)
    - HTTPS (Port 443)
    - DNS (Port 53)
    - SSH (Port 22)
10. Hping2 can often work even when normal Ping fails because many firewalls block **ICMP** but allow **TCP** traffic.
