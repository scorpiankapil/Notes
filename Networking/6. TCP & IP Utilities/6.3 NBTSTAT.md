# NBTSTAT

**NBTSTAT (NetBIOS over TCP/IP Statistics)** is a Windows command-line tool used to display and troubleshoot **NetBIOS over TCP/IP** connections and name resolution information.

It helps administrators view:
- NetBIOS names
- NetBIOS name cache
- Active NetBIOS sessions
- Remote computer information

NBTSTAT is used to:
- Troubleshoot NetBIOS name resolution issues
- View NetBIOS names registered on a computer
- Check active NetBIOS connections
- Diagnose WINS-related problems

# How NetBIOS over TCP/IP (NetBT) Works

1. The user enters a **computer name (NetBIOS name)** instead of an IP address.
    
    Example:
    
    ```
    \\FILESERVER
    ```
    
2. The client computer receives the NetBIOS name.
3. NetBIOS over TCP/IP (NetBT) starts the name resolution process.
4. The system checks the **NetBIOS Name Cache** to see if the IP address is already known.
5. If not found in the cache, it checks the **WINS Server** (if configured).
6. If no WINS server is available, it checks the **LMHOSTS file**.
7. If still not found, it sends a **NetBIOS broadcast** on the network asking:
    
    ```
    Who is FILESERVER?
    ```
    
8. The computer named **FILESERVER** responds with its IP address.
9. NetBT converts:
    
    ```
    FILESERVER     ↓192.168.1.10
    ```
    
10. The IP address is stored in the NetBIOS cache for future use.
11. The client now knows the destination IP address.
12. Normal TCP/IP communication begins using that IP address.
13. The user successfully accesses the remote computer or shared resource.
