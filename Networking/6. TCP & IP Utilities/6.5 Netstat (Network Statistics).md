# Netstat (Network Statistics)

**NETSTAT (Network Statistics)** is a command-line tool used to display network connections, listening ports, routing tables, and network statistics on a computer.

It helps administrators troubleshoot network connectivity and identify which applications are using network connections.

- View active network connections
- Check open and listening ports
- Identify connected hosts
- Troubleshoot network issues
- Detect suspicious connections

# How Netstat Works

1. A client application (like a web browser) creates a network connection.
2. TCP establishes a session using the **Three-Way Handshake**.
3. Netstat reads information about active connections from the TCP/IP stack.
4. It displays the **protocol** being used (TCP/UDP).
5. It shows the **Local Address** (your IP and port).
6. It shows the **Foreign Address** (remote IP and port).
7. It displays the **connection state** (LISTENING, ESTABLISHED, TIME_WAIT, etc.).
8. It can show active connections, listening ports, protocol statistics, and the routing table.
9. Administrators use Netstat to monitor and troubleshoot network connections.


|State|Explanation|
|---|---|
|**SYN_SENT**|Client has sent a SYN packet and is waiting for a response from the server (connection request sent).|
|**SYN_RECEIVED**|Server has received the SYN packet and sent a SYN-ACK back to the client.|
|**ESTABLISHED**|Connection is successfully established and data can be exchanged.|
|**LISTEN**|Server is waiting for incoming connection requests on a port.|
|**FIN_WAIT_1**|Client has initiated connection termination by sending a FIN packet.|
|**TIME_WAIT**|Client waits for a short period after closing the connection to ensure all packets are received.|
|**CLOSE_WAIT**|Server has received a FIN from the client and is preparing to close the connection.|
|**FIN_WAIT_2**|Client has received acknowledgment for its FIN and is waiting for the server's FIN.|
|**LAST_ACK**|Server has sent its FIN packet and is waiting for the final ACK from the client.|
|**CLOSED**|Connection has been completely terminated and resources have been released.|

# Common Netstat Commands for Troubleshooting

### Why Use Netstat for Troubleshooting?

- Monitor active TCP/IP connections.
- View open and listening ports.
- Identify suspicious network activity.
- Detect unauthorized services or Trojans.
- Find which program is using a specific port.
- Check routing information.
- View protocol statistics.

|Command|Purpose|
|---|---|
|`netstat -a`|Displays all active connections and listening ports|
|`netstat -e`|Displays Ethernet statistics|
|`netstat -n`|Shows addresses and ports in numerical format|
|`netstat -s`|Displays protocol statistics (TCP, UDP, IP, ICMP)|
|`netstat -p tcp`|Displays TCP connections only|
|`netstat -p udp`|Displays UDP connections only|
|`netstat -r`|Displays routing table|
|`netstat -o`|Displays Process ID (PID) for each connection|
|`netstat -nao`|Shows all connections, numerical addresses, and PID|
|`netstat <interval>`|Refreshes output after a specified interval|
