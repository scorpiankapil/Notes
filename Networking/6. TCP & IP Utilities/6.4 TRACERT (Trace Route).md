# TRACERT (Trace Route)

**Traceroute (Tracert in Windows)** is a network troubleshooting tool that shows the complete path a packet takes from a source device to a destination device. It displays every router (hop) between the source and destination and measures the response time of each hop.

This helps network administrators identify where delays, packet loss, or routing problems are occurring.

TRACERT helps to:
- Identify network paths
- Troubleshoot network issues
- Find where a connection is failing
- Measure response time between hops

# How Tracert Works (Simple and Easy Terms)

1. A user runs the **tracert** command to check the path to a destination.
2. Tracert sends a packet toward the destination.
3. The first router receives the packet and sends a reply back.
4. Tracert records the first router (**Hop 1**).
5. Tracert sends another packet that travels one router farther.
6. The next router replies back, and Tracert records it (**Hop 2**).
7. This process continues, discovering one router at a time.
8. Eventually, the packet reaches the destination server.
9. Tracert displays all routers (**hops**) between the source and destination.
10. It also shows how long each hop took to respond.

##### Which Packet Does Tracert Send?

It depends on the operating system:

|Operating System|Packet Sent|
|---|---|
|**Windows (tracert)**|ICMP Echo Request packets|
|**Linux/macOS (traceroute)**|UDP packets (by default)|
