# IPCONFIG (Internet Protocol Configuration)

**IPCONFIG (Internet Protocol Configuration)** is a Windows command-line utility used to display and manage TCP/IP network configuration settings.

It helps administrators troubleshoot network connectivity and view details about network adapters.

### What Information Does IPCONFIG Show?

1. Host Name (Computer Name)
2. IP Address
3. Subnet Mask
4. Default Gateway
5. MAC Address (Physical Address)
6. DNS Server Address
7. DHCP Server Address
8. Lease Information
9. WINS Information

# Common IPCONFIG Commands

| Command                | Purpose                                               |
| ---------------------- | ----------------------------------------------------- |
| `ipconfig`             | Displays IP address, subnet mask, and default gateway |
| `ipconfig /all`        | Displays complete TCP/IP information                  |
| `ipconfig /release`    | Releases the current DHCP-assigned IP address         |
| `ipconfig /renew`      | Requests a new IP address from the DHCP server        |
| `ipconfig /displaydns` | Displays the DNS resolver cache                       |
| `ipconfig /flushdns`   | Clears the DNS resolver cache                         |
