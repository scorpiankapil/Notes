# Hostname

**Hostname** is a command used to display the **computer name (hostname)** of the local system.

-  Find the computer's name.
- Verify system identity on a network.
- Useful for troubleshooting and administration.

```
hostname
> Kapil
```

# Host

**Host** is a Linux DNS lookup utility used to query DNS records and resolve domain names to IP addresses.

```
host www.gleneclarke.com
```

```
www.gleneclarke.com
          ↓
DNS Query
          ↓
IP Address Returned
```

```
host -t MX glensworld.loc
```
