# TFTP (Trivial File Transfer Protocol)

**TFTP (Trivial File Transfer Protocol)** is a simple file transfer protocol used to transfer files between devices over a network.

It is a lightweight version of FTP and does not require username or password authentication.

- It is a connectionless file transfer protocol
- It uses UDP
- Port 69
- Use to transfer files between devices on a network
- No Authentication requires

# How TFTP Works

1. A client sends a request to a TFTP server.
2. TFTP uses **UDP Port 69** for communication.
3. No username or password is required.
4. The server receives the request.
5. The file is uploaded or downloaded.
6. After the transfer is complete, the connection ends.
