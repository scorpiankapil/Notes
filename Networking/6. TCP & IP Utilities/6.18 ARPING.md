# ARPING

**ARPING** is a Linux network utility that combines the concept of **Ping** and **ARP**. It sends **ARP requests** to a target IP address and receives **ARP replies** containing the target device's **MAC address**.

Since ARP is used to map an IP address to a MAC address, ARPING helps verify that a device exists on the local network and reveals its MAC address.

```
arping 192.168.100.201
```

|Ping|Arping|
|---|---|
|Uses ICMP|Uses ARP|
|Returns reply status|Returns reply + MAC address|
|Works across networks|Works on local network|
|Checks connectivity|Checks connectivity and MAC address|

# How Arping Works

1. You run the `arping` command and specify an IP address.
2. Arping sends an **ARP Request** on the local network.
3. The ARP Request asks:
    
    ```
    Who has 192.168.1.10?
    ```
    
4. All devices on the local network receive the request.
5. Only the device with the matching IP address replies.
6. The device sends back its **MAC Address**.
7. Arping receives the reply.
8. Arping displays the target's:
    - IP Address
    - MAC Address
    - Response Time
9. This confirms that the device is online and reachable.
10. Unlike Ping, Arping also tells you the device's **MAC Address**.
