# ARP (Address Resolution Protocol)

**ARP (Address Resolution Protocol)** is a protocol used to find the **MAC address** of a device when its **IP address** is known.

Since devices communicate on a local network using MAC addresses, ARP helps convert an IP address into the corresponding MAC address.

**IP Address tells "Who?"**  
**MAC Address tells "Where exactly?"**

#### Why is ARP Needed?

When a computer wants to send data on a local network, it needs both the **destination IP address** and the **destination MAC address**. Usually, the computer knows the IP address but not the MAC address.

**ARP (Address Resolution Protocol)** solves this problem by finding the MAC address associated with a known IP address, allowing the data to be delivered to the correct device.

## Working of ARP

1. A computer wants to send data to another device and knows its **IP address**.
2. It checks its **ARP cache** to see if the MAC address is already stored.
3. If the MAC address is not found, the computer sends an **ARP Request** to all devices on the network:
    - "Who has this IP address?"
4. The device with that IP address sends back an **ARP Reply** containing its MAC address.
5. The sender stores the MAC address in its ARP cache.
6. The sender then uses that MAC address to send the data to the destination device.

### ARP Cache

**ARP Cache** is a temporary table stored in a computer's memory that keeps a record of **IP addresses and their corresponding MAC addresses**.

It helps the computer avoid sending an ARP request every time it needs to communicate with a device on the local network.

**View ARP Cache :**
```
arp -a
```

**Adding Static ARP Entries :**
```
arp -s <IP Address> <MAC Address>
```

**Deleting ARP Entries :**
```
arp -d <IP Address>
```

## ARP Cache Aging

**ARP Cache Aging** is the process of automatically removing old or unused ARP entries from the ARP cache after a certain period of time.

This ensures that the ARP cache contains up-to-date IP-to-MAC address mappings.

We need ARP Cache Aging
- Without aging, old or incorrect entries could remain in the cache and cause communication problems.
- Suppose a device's MAC address changes or the device leaves the network.

## RARP (Reverse Address Resolution Protocol)

**RARP (Reverse Address Resolution Protocol)** is a protocol used to find the **IP address** of a device when its **MAC address** is known.

It is the opposite of ARP.

We need RARP:
- In older networks, some devices (such as diskless workstations) knew only their MAC address when they started.
- They needed a way to obtain their IP address.
- RARP was used for this purpose.
