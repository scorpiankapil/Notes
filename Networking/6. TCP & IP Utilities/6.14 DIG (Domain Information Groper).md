# DIG (Domain Information Groper)

**DIG (Domain Information Groper)** is a command-line DNS troubleshooting tool used to query DNS servers and obtain detailed information about domain names, IP addresses, and DNS records.

It is more powerful and detailed than **NSLOOKUP**.

- Find the IP address of a domain name.
- Verify DNS records.
- Troubleshoot DNS issues.
- Check DNS server responses.
- View detailed DNS information.

# Working of DIG

1. The user enters a domain name.
2. DIG sends a query to a DNS server.
3. The DNS server searches for the requested record.
4. The DNS server returns the result.
5. DIG displays detailed DNS information.

```
dig google.com

dig google.com MX

dig google.com NS

dig -x 8.8.8.8
```

# Common DNS Records Checked with DIG

|Record Type|Purpose|
|---|---|
|A|Domain → IPv4 Address|
|AAAA|Domain → IPv6 Address|
|MX|Mail Server Records|
|NS|Name Server Records|
|CNAME|Alias Records|
|PTR|Reverse DNS Lookup|
