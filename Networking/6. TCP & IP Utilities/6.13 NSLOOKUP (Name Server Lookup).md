# NSLOOKUP (Name Server Lookup)

**NSLOOKUP (Name Server Lookup)** is a network troubleshooting tool used to query **DNS servers** and obtain information about domain names and IP addresses.

It helps verify whether DNS is resolving names correctly.

- Find the IP address of a domain name
- Find the domain name associated with an IP address
- Troubleshoot DNS issues
- Verify DNS records
- Check which DNS server is responding

# Working of NSLOOKUP

1. The user enters a domain name or IP address.
2. NSLOOKUP sends a query to the configured DNS server.
3. The DNS server searches its records.
4. The DNS server returns the result.
5. NSLOOKUP displays the information to the user.

```
nslookup google.com
```


# NSLOOKUP Modes

NSLOOKUP can work in **two modes**:

|Mode|Description|
|---|---|
|**Non-Interactive Mode**|Executes a single DNS query and exits immediately.|
|**Interactive Mode**|Opens an NSLOOKUP prompt where multiple DNS queries can be performed.|
