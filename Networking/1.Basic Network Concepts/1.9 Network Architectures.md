A network architecture defines how a network is designed and how devices communicate with each other. A network architecture is made using:

- Network topology
- Cable type
- Access method

Before learning Ethernet architectures, two communication methods are important.
# Baseband

Baseband communication sends digital signals through a single channel and uses the entire bandwidth of the cable. The signal is transmitted as electrical pulses or light signals depending on the cable type.

Baseband is bidirectional, which means the same channel can be used for both sending and receiving data.

### Important Points

- Uses digital signals
- Single communication channel
- Uses full bandwidth
- Bidirectional communication
- Commonly used in Ethernet networks

# Broadband

Broadband communication sends data as analog signals using electromagnetic or optical waves. The bandwidth is divided into multiple channels, so multiple transmissions can happen at the same time.

Broadband is unidirectional, so separate paths or frequencies are needed for sending and receiving data.

### Important Points

- Uses analog signals
- Multiple channels/frequencies
- Multiple transmissions at the same time
- Unidirectional communication
- Uses separate send and receive paths

# Ethernet

Ethernet is the most popular network architecture used in LANs and follows the IEEE 802.3 standard. Ethernet networks mainly use:

- Baseband communication
- CSMA/CD access method

In Ethernet naming:

- Number = speed of network
- Base = baseband transmission
- Last letter = cable type

Example:  
10BaseT means:

- 10 Mbps speed
- Baseband communication
- Twisted-pair cable

# 10Base2

10Base2 is an Ethernet architecture that runs at 10 Mbps and uses thinnet coaxial cable (RG-58). It mainly uses a bus topology.

The “2” in the name represents approximately 200 meters cable distance (actual distance is 185 meters).

### Important Points

- Speed: 10 Mbps
- Cable: Thinnet (RG-58)
- Topology: Bus
- Access Method: CSMA/CD
- Max distance: 185 meters per segment
- Maximum 30 hosts per segment
- Minimum distance between hosts: 0.5 meters

# 10Base5

10Base5 also runs at 10 Mbps but uses thicknet coaxial cable (RG-8). Thicknet cable is thicker and allows signals to travel longer distances than thinnet.

The “5” represents approximately 500 meters cable distance.

### Important Points

- Speed: 10 Mbps
- Cable: Thicknet (RG-8)
- Topology: Bus
- Access Method: CSMA/CD
- Max distance: 500 meters per segment
- Maximum 100 hosts per segment
- Minimum distance between hosts: 2.5 meters

# 10BaseT

10BaseT uses twisted-pair cable and a star topology. All devices connect to a central hub or switch.

It mainly uses CAT 3 UTP cable, but higher cables like CAT 5 can also work because they are backward compatible.

### Important Points

- Speed: 10 Mbps
- Cable: CAT 3 UTP
- Topology: Star
- Access Method: CSMA/CD
- Uses RJ-45 connector
- Uses hub or switch

# 10BaseFL

10BaseFL is a fiber-optic Ethernet architecture. It is mainly used as a backbone network for longer distances.

### Important Points

- Speed: 10 Mbps
- Cable: Fiber-optic
- Used for long-distance communication
- Commonly used as backbone connection

# Fast Ethernet (100BaseTX and 100BaseFX)

100BaseTX and 100BaseFX are part of the 100BaseX family, known as Fast Ethernet. Both architectures run at 100 Mbps, use a star topology, and use CSMA/CD as the access method.

The main difference between them is the type of cable used.

## 100BaseTX

100BaseTX uses CAT 5 twisted-pair cable. It uses two wire pairs (4 wires) for communication.

### Important Points

- Speed: 100 Mbps
- Cable: CAT 5 UTP
- Uses 4 wires
- Topology: Star
- Access Method: CSMA/CD

## 100BaseFX

100BaseFX uses fiber-optic cable instead of twisted-pair cable. It uses two fiber strands for communication.

### Important Points

- Speed: 100 Mbps
- Cable: Fiber-optic
- Uses 2 fiber strands
- Topology: Star
- Access Method: CSMA/CD
- Better for longer distances

# Gigabit Ethernet

Gigabit Ethernet runs at 1000 Mbps (1 Gbps) and supports twisted-pair, coaxial, and fiber-optic cables.

There are two major standards:

- IEEE 802.3z
- IEEE 802.3ab

## IEEE 802.3z

### 1000BaseSX

Uses multimode fiber (MMF) for short-distance communication.

- Speed: 1 Gbps
- Cable: MMF
- Max distance: 550 meters

### 1000BaseLX

Uses single-mode fiber (SMF) for long-distance communication.

- Speed: 1 Gbps
- Cable: SMF
- Max distance: 3 kilometers

### 1000BaseCX

Uses coaxial cable.

- Speed: 1 Gbps
- Max distance: 25 meters

## IEEE 802.3ab (1000BaseTX)

1000BaseTX uses twisted-pair cable and RJ-45 connectors.

Unlike 100BaseTX, it uses all 8 wires in the cable.

### Important Points

- Speed: 1 Gbps
- Cable: CAT 5e or CAT 6
- Uses RJ-45 connector
- Uses all four wire pairs (8 wires)
- Access Method: CSMA/CD

# 10-Gigabit Ethernet

10-Gigabit Ethernet runs at 10 Gbps (10,000 Mbps) and mainly uses fiber-optic cables for very high-speed communication.

## 10GBaseSR

Uses multimode fiber for short distances.

- Distance: 100 meters

## 10GBaseLR

Uses single-mode fiber for long distances.

- Distance: 10 kilometers

## 10GBaseER

Uses single-mode fiber for extra-long distances.

- Distance: 40 kilometers

## 10GBaseT

Uses CAT 6 UTP cable.

- Distance: 100 meters

### Important Points

- Speed: 10 Gbps
- Mostly used in data centers and enterprise networks
- Fiber-optic cable commonly used for high speed and long distance
