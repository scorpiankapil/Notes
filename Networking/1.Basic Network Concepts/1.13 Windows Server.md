# Windows Servers

Windows Server is a popular Network Operating System (NOS) developed by Microsoft. It provides many built-in network services to clients on the network.

Some common services provided by Windows Server are:

- File and print services
- DNS and WINS services
- DHCP services
- Directory services
- Web services
- E-mail services
- Group policies

## File and Print Services

These services allow administrators to share files and printers with users on the network.

## DNS and WINS Services

These services provide name resolution:

- DNS resolves domain names
- WINS resolves NetBIOS names

## DHCP Services

DHCP automatically assigns IP addresses to client systems on the network.

## Directory Services

Directory services store user accounts and network objects centrally.

Microsoft’s directory service is called:

- Active Directory

## Web Services

These services allow hosting of websites and intranet applications on the server.

## E-mail Services

Windows Server can send e-mails using SMTP (Simple Mail Transfer Protocol).

## Group Policies

Group policies allow administrators to apply settings to client computers from a central location.

Examples:

- Folder redirection
- File permissions
- Software installation
- User rights

# Clients and Resources

A client operating system is an important part of networking with a Network Operating System (NOS). The client system needs special software called a redirector.

A redirector sends requests from the client computer to the network server whenever the client wants to access a network resource such as files or printers.

Client software is needed in both:

- Peer-to-peer networks
- Client/server networks

Examples of client operating systems:

- Windows XP Professional
- Windows 2000 Professional
- Windows NT Workstation 4.0
- Windows 95/98
- Windows for Workgroups

Windows servers are popular because they support many different client operating systems, including:

- Windows clients
- Macintosh clients
- NetWare clients
- UNIX clients

# Directory Services

In Windows Server, the server that stores user accounts is called a Domain Controller.

The database that stores user accounts is called:

- Active Directory Database

Active Directory is Microsoft’s directory service.

When a user logs in:

1. User enters username and password
2. Login request goes to the domain controller
3. Domain controller checks the information
4. If correct, access to network resources is given

Directory services also store network objects such as:

- Printers
- Folders
- User accounts

Users can search and access these resources through the directory service.
