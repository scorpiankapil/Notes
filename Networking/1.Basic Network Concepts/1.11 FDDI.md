FDDI is a network architecture that uses fiber-optic cable for high-speed communication.

It runs at:

- 100 Mbps speed

FDDI uses:

- Token-passing access method
- Dual ring topology

In FDDI, two rings are used:

- Primary ring → normal data transfer
- Secondary ring → backup if primary ring fails

Because of the second ring, FDDI provides fault tolerance and high reliability.

FDDI mainly uses fiber-optic cable, so it supports long-distance communication and is resistant to electrical interference.

### Important Points

- Full form: Fiber Distributed Data Interface
- Speed: 100 Mbps
- Uses fiber-optic cable
- Uses token passing
- Uses dual ring topology
- Provides backup and fault tolerance
- Used for backbone networks and large organizations
