An access method decides how a device places data on the network wire. It determines whether a device can send data immediately or must wait for its turn.

The three main access methods are:

- CSMA/CD
- CSMA/CA
- Token Passing

# CSMA/CD

CSMA/CD stands for Carrier Sense Multiple Access with Collision Detection.

In this method, a host first checks the wire to see if it is free before sending data. If the wire is busy, the host waits. If the wire is free, the host sends the data.

Sometimes two devices may send data at the same time, causing a collision. When a collision happens, the devices detect it, wait for some time, and retransmit the data.

### Important Points

- Used in Ethernet networks
- Devices check the wire before sending data
- Collision can happen
- Data is retransmitted after collision

# CSMA/CA

CSMA/CA stands for Carrier Sense Multiple Access with Collision Avoidance.

In this method, the host checks whether the wire is free. Before sending actual data, it sends dummy data to avoid collisions. If no collision occurs, the real data is sent.

## How CSMA/CA Works

1. Device checks if channel is free.
2. If free, it sends RTS (Request To Send) packet. (RTS is a small control packet used in CSMA/CA networks to request permission before sending actual data.)
3. Receiver replies with CTS (Clear To Send).
4. Then actual data is transmitted.
5. Other devices wait after hearing RTS/CTS.

### Important Points

- Tries to avoid collisions before sending data
- Uses dummy data first
- Less popular than CSMA/CD

# Token Passing

In token passing, a small packet called a token moves continuously in the network.

If a computer wants to send data, it must first wait for the token.

- If the computer gets the token → it can send data
- If it does not have the token → it must wait

After sending the data, the token moves to the next computer.

Because only one token exists, only one computer can send data at one time, so collisions do not happen.

### Simple Example

Think of the token like a microphone in a classroom:

- Only the student holding the microphone can speak
- Others must wait for their turn
