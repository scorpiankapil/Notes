In a typical network, users work on computers called workstations. A workstation is also known as a client and usually runs a client operating system such as Windows XP or Linux. Users use applications like word processors and spreadsheet programs on these systems.

Users usually store their files on a central server so that files can be shared with other users on the network. A server is a powerful computer with more memory and disk space than client workstations. It also runs special server software.

A server can provide different services such as file sharing, printer sharing, web pages, and e-mail services to users on the network.

The term host refers to any device connected to a network that can send or receive data. A host can be a server, workstation, a printer with its own network card, or router. Any device connected to the network is called a host.
