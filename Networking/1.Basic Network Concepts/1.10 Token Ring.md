Token Ring was a major competitor to Ethernet in the past. It runs at speeds of 4 Mbps or 16 Mbps.

Token Ring uses a star-ring topology, which means it physically looks like a star topology but logically works like a ring topology.

Devices in a Token Ring network connect to a central device called an MAU (Multistation Access Unit) or MSAU.

Token Ring can use:

- IBM proprietary cables
- CAT 3 UTP cable
- CAT 5 UTP cable

Token Ring uses the token-passing access method. A device must wait for the token before sending data.

Since only one token exists, collisions cannot occur in a Token Ring network.

Token Ring follows the IEEE 802.5 standard.

### Important Points

- Speed: 4 Mbps or 16 Mbps
- Uses Token Passing
- No collisions occur
- Uses star-ring topology
- Central device = MAU/MSAU
- It follows IEEE standard: 802.5
