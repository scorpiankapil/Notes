# UNIX/Linux

UNIX is a powerful operating system originally developed by Bell Labs. It is widely used for:

- Networking
- Database management
- Server systems

UNIX became popular because of three major features:

- Multitasking
- Multiuser support
- Networking capabilities

## Multitasking

UNIX can run many processes at the same time. It can perform background tasks while users continue working on applications in the foreground.

## Multiuser Support

Multiple users can use the same UNIX system simultaneously.

## Networking Capabilities

UNIX has strong built-in networking support and many powerful networking utilities. Many UNIX networking tools were later used in other operating systems as well.

# Linux

Linux is a UNIX-like operating system and is considered a popular cousin of UNIX. Linux is becoming widely used as both:

- Server operating system
- Client operating system

# Clients and Resources

Modern versions of UNIX and Linux are very different from older command-line-only systems.

Today, most Linux operating systems include:

- Graphical User Interface (GUI)
- Mouse support
- Built-in configuration tools
- Common applications

Users can configure system settings using graphical tools instead of only command-line commands.

Most Linux systems also come with programs such as:

- Text editor
- Calculator
- Other utility applications

Although UNIX/Linux is often associated with command-line usage, many tasks can now be performed through the graphical shell as well.

# Directory Services in UNIX/Linux

The standard directory service used in UNIX and Linux is called:

- NIS (Network Information Service)

NIS is used to store a central list of network objects such as:

- Users
- Groups
- Printers

Later, NIS was improved and replaced by:

- NIS+
- LDAP

NIS allows UNIX and Linux clients to authenticate and access network resources.

NIS can also work with:

- Microsoft Active Directory
- Novell eDirectory

This allows directory information to be synchronized between different operating systems and servers.

Similar to Active Directory and eDirectory, NIS acts as a central repository for network resources and synchronizes information across UNIX/Linux servers.
