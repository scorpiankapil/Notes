A Network Operating System (NOS) is software installed on a server that provides network services to clients and devices on the network.

After connecting cables, hubs, and computers, a network operating system is installed to manage the network and provide services.

Some common services provided by an NOS are:

- File sharing
- Printer sharing
- DNS services
- User logon services
- Directory services

The most popular network operating systems are:

- Windows 2000 Server / Windows Server 2003/2008
- Novell NetWare
- UNIX

Windows 2000 and Windows Server 2003 are based on Windows NT technology and are successors to Windows NT Server.
