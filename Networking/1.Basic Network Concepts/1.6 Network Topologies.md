A network topology is the physical layout of computers, cables, and devices in a network.

The main types of network topologies are:

- Bus topology
- Star topology
- Mesh topology
- Ring topology
- Hybrid topology
- Wireless topology

# Bus Topology

A bus topology uses one main cable called a backbone or trunk to connect all systems together. Signals travel in both directions through the cable. Terminators are placed at both ends to prevent signal bounce.

If the cable breaks, the entire network goes down.

### Advantages

- Low cost
- Easy installation
- Less cable required
- No hub required
- Failure of one workstation does not affect the network

### Disadvantages

- Difficult troubleshooting
- Poor scalability
- Cable break causes whole network failure

# Star Topology

In a star topology, all computers connect to a central device such as a hub or switch.

If one cable breaks, only that workstation is affected. If the hub fails, the whole network fails.

### Advantages

- Easy to add new systems
- Easy troubleshooting
- Good scalability
- Centralized management

### Disadvantages

- Hub failure affects entire network
- More cabling required
- Higher cost than bus topology

# Mesh Topology

In a mesh topology, every computer is connected to every other computer.

### Advantages

- Very high fault tolerance
- Multiple paths for data
- Network rarely fails due to cable fault

### Disadvantages

- Very expensive
- Difficult to manage
- Requires many cables and interfaces

# Ring Topology

In a ring topology, computers are connected in a circular form. Signals move in one direction, and each computer regenerates the signal.

### Advantages

- Low signal loss
- Strong signal transmission
- Less retransmission needed

### Disadvantages

- Failure of one system can affect the network
- Difficult troubleshooting
- Network interruption during changes

# Hybrid Topology

A hybrid topology is a combination of two or more topologies.

Examples:

- Star-Bus topology
- Star-Ring topology

It is commonly used in modern networks.

# Wireless Topology

A wireless topology uses radio frequencies instead of cables. Wireless access points or cells allow devices to connect wirelessly.

### Advantages

- Less cabling required
- Easy device mobility
- Easy troubleshooting of failed devices

### Disadvantages

- Signal interference
- Signal blockage
- Signal interception/security risks

# Point-to-Point Topology

A point-to-point topology connects one system directly to another system.

Example:

- Two computers connected using a crossover cable

# Point-to-Multipoint Topology

A point-to-multipoint topology uses one central device connected to multiple devices.

Commonly used in wireless networks.

# Segments and Backbones

A network segment is a part of a network made using one cable length or multiple connected cables without interruption from devices like bridges or routers. Large networks are often divided into multiple segments to reduce network traffic and improve performance.

Each segment can contain multiple clients, servers, and hubs connected together.

A backbone is the main cable or central connection of the network that connects different network segments together. It acts like the main highway of the network.

In a bus network, smaller cables called drop cables connect workstations to the backbone.

A backbone can also be wireless. For example, a satellite can connect multiple LANs together to create a WAN.
