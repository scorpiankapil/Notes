Organizations use different types of networks based on their size, structure, and budget. Networks are mainly divided into two types:

1. Peer-to-Peer Network
2. Server-Based Network

## Peer-to-Peer Network

A peer-to-peer network has no dedicated server. All workstations are connected together to share files, printers, and other resources. In this type of network, every computer is considered equal and can act as both client and server.

Peer-to-peer networks are mainly used in homes or small companies because they are low-cost and easy to set up. Modern operating systems like Windows XP and Windows Vista already support peer-to-peer networking.

The disadvantage of a peer-to-peer network is the lack of centralized administration. User accounts and security settings must be configured on every system separately.

Peer-to-peer networks usually contain fewer than 10 systems. In Microsoft operating systems, only 10 concurrent network connections are allowed.

### Important Points

- No dedicated server
- All systems are equal
- Low-cost network solution
- Best for small networks
- Also called a workgroup in Microsoft
- Difficult centralized management

## Server-Based Network

A server-based network uses a dedicated server to manage users, files, printers, and other resources. User accounts and shared data are stored centrally on the server.

The main advantage of a server-based network is centralized administration. It becomes easier to manage permissions, security, backups, and resources from one location.

A server can provide different services depending on its role.

### Types of Servers

- File and Print Server
- Application Server
- Web Server
- Directory Server

## File and Print Server

These servers share files and printers with users on the network.

Characteristics:

- Large memory
- Fast hard disks
- Multiple CPUs
- Fast network adapters
- Redundant power supplies

They also use ACL (Access Control List) to control access to files and printers.
ACL: An Access Control List (ACL) is a set of rules used to control network traffic and enhance security by permitting or denying specific traffic based on defined criteria. ACLs are commonly applied to routers, firewalls, or servers to filter traffic and protect resources.

## Application Server

An application server runs special software such as:

- Microsoft SQL Server
- Oracle
- Microsoft Exchange Server
- IBM Lotus Domino

These servers provide applications and database services to users.

## Web Server

A web server uses HTTP to host websites and web applications on the Internet or intranet.

Examples:

- Apache
- Microsoft IIS

## Directory Server

A directory server stores user accounts and login information in a directory database. It manages authentication and allows users to access network resources.

A single server can perform multiple roles at the same time, which reduces the cost of the network.
