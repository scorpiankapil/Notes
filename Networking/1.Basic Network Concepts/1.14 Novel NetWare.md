# Novell NetWare

Novell NetWare is a powerful Network Operating System (NOS) used in many large organizations. It started as a college project and later became a popular server operating system.

NetWare provides many built-in network services such as:

- File and print services
- DNS services
- DHCP services
- Directory services
- Web server services

# Difference Between Windows Server and NetWare

Earlier versions of NetWare mainly used a text-based server console.

Most administration tasks such as:

- User account management
- File system management

were done from a client workstation instead of directly from the server.

In Windows Server, management tools are already installed on the server, making administration easier.
