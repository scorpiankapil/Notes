NetBEUI (NetBIOS Extended User Interface) is a transport protocol developed by IBM and later adopted by Microsoft for older versions of Windows and DOS.

NetBEUI was commonly used in small Microsoft networks such as:

- Windows 3.11
- Windows 95
- Windows 98

NetBEUI is a nonroutable protocol, which means data cannot pass through a router to reach other networks. Communication is limited only to the local LAN.

Because it cannot route packets, NetBEUI is rarely used in modern networks.

One major advantage of NetBEUI is that it is very simple and efficient with very little overhead.

It is also very easy to install and configure. Usually, you only need:

- Install the protocol
- Assign a unique computer name

and the protocol starts working.

### Important Points

- Full form: NetBIOS Extended User Interface
- Developed by IBM
- Adopted by Microsoft
- Used in older Windows networks
- Nonroutable protocol
- Communication limited to local LAN
- Very simple and fast
- Minimal configuration required
