# Routable Protocols

A **Routable Protocol** is a protocol that allows data packets to travel from one network to another through routers. These protocols contain logical addressing information, such as IP addresses, which routers use to identify the destination network and forward the data correctly. Routable protocols are important for communication over large networks, including the Internet.

For example, in **TCP/IP**, every device has an IP address. When data is sent, routers examine the IP address and decide the best path to deliver the packet to another network.

### Examples

- TCP/IP
- IPX/SPX

### Features

- Can communicate across multiple networks
- Uses logical addressing
- Supported by routers
- Used in large enterprise networks and the Internet

---

# Non-Routable Protocols

A **Non-Routable Protocol** is a protocol that cannot send data outside the local network because it does not contain logical addressing information required by routers. These protocols work only within a single LAN (Local Area Network) and cannot communicate between different networks.

For example, NetBEUI works well in small local networks for file and printer sharing, but routers cannot forward its packets to another network.

### Examples

- NetBEUI

### Features

- Works only within a local network
- Cannot pass through routers
- Simple and fast for small LANs
- Not suitable for large networks or the Internet


# Main Difference

Routable protocols are designed for communication between different networks using routers, while non-routable protocols work only inside a local network and cannot travel across routers.
