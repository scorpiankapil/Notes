# Network Protocols

A network protocol is a set of rules or a language used by computers to communicate with each other on a network.

For two systems to communicate successfully, both systems must use the same protocol. If different protocols are used, communication cannot happen properly.

Just like two people need to speak the same language to understand each other, computers also need the same network protocol to exchange data.

The first step in networking is making sure that both systems have the same protocol installed.

Four major network protocols are:

- NetBEUI
- IPX/SPX
- AppleTalk
- TCP/IP

## NetBEUI

NetBEUI (NetBIOS Extended User Interface) is a simple and fast protocol mainly used in small networks.

### Important Points

- Easy to configure
- Fast in small networks
- Non-routable protocol
- Mainly used in older Windows networks

## IPX/SPX

IPX/SPX is a protocol developed by Novell for NetWare networks.

### Important Points

- Used in Novell NetWare
- Routable protocol
- Used in older enterprise networks

## AppleTalk

AppleTalk is a protocol developed by Apple for Macintosh systems.

### Important Points

- Used in Apple Macintosh networks
- Easy configuration
- Supports file and printer sharing

## TCP/IP

TCP/IP is the most widely used protocol today and is the main protocol of the Internet.

### Important Points

- Used on the Internet
- Routable protocol
- Supports communication between different networks
- Most popular network protocol today
