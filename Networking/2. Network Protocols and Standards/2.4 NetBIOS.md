NetBIOS (Network Basic Input/Output System) works closely with NetBEUI for communication between systems on a network.

NetBIOS is an API (Application Programming Interface) used by applications to communicate with remote systems over the network. When NetBEUI is installed, NetBIOS is automatically included with it.

NetBEUI depends on NetBIOS for session management functions.

Both NetBIOS and NetBEUI are nonroutable, which means they normally cannot pass data through routers to other networks. However, NetBIOS can work with routable protocols such as:

- TCP/IP
- IPX/SPX

This allows NetBIOS traffic to move across multiple networks.

# NetBIOS Communication Modes

NetBIOS supports two communication modes:

## Session Mode

Session mode is connection-oriented communication.

In this mode, NetBIOS first establishes a connection (session) with the target system before data transfer starts.

NetBIOS is responsible for:

- Creating the session
- Monitoring communication
- Detecting transmission errors
- Retransmitting lost or corrupted data

This makes session mode reliable.

### Important Points

- Connection-oriented communication
- Session must be established first
- Supports error detection and recovery
- Reliable communication

## Datagram Mode

Datagram mode is connectionless communication.

In this mode:

- No session is created
- Data is sent directly
- Mainly used for broadcasts

Datagram mode does not provide:

- Error detection
- Error correction
- Retransmission support

The application itself handles errors if needed.

### Important Points

- Connectionless communication
- Used for broadcasts
- Faster but less reliable
- No error recovery support

## Name Service

NetBIOS uses NetBIOS names (computer names) to identify devices on the network.
