## Definition

TCP/IP (Transmission Control Protocol / Internet Protocol) is the most widely used protocol suite today.

It is a routable protocol and is the main protocol used on:

- Internet
- LANs
- WANs

TCP/IP is commonly associated with:

- UNIX systems
- Linux systems

TCP/IP was originally developed in the 1970s by:

- DARPA (Defense Advanced Research Projects Agency)
- U.S. Department of Defense (DOD)

It was designed to connect different types of computer systems across large networks.

# Use of TCP/IP

TCP/IP is used for:

- Internet communication
- Web browsing
- File transfer
- E-mail communication
- Communication between different operating systems and networks

One major goal of TCP/IP was to allow communication between heterogeneous systems (different systems and platforms).

Because of this capability, TCP/IP became the protocol of the Internet.

# Important Feature of TCP/IP

TCP/IP was designed to handle unstable network conditions.

If one path fails, TCP/IP can:

- Reroute packets through another path

This makes TCP/IP:

- Reliable
- Flexible
- Robust

# TCP (Transmission Control Protocol)

## Definition

TCP is responsible for reliable communication between systems.

## Functions of TCP

- Establishes connection
- Ensures reliable delivery
- Detects errors
- Retransmits lost packets
- Maintains correct packet order

TCP is:

- Connection-oriented
- Reliable

## Example

When downloading a file:

1. TCP creates a connection
2. Sends data packets
3. Checks packet delivery
4. Resends missing packets if needed

# IP (Internet Protocol)

## Definition

IP is responsible for:

- Addressing
- Routing packets across networks

Each device gets a unique IP address.

IP is:

- Connectionless
- Unreliable

Meaning:

- No session setup
- No delivery guarantee

## Example

When opening a website:

1. IP adds source and destination IP addresses
2. Routers forward packets
3. Packets reach destination network

# Drawbacks of TCP/IP

## 1. Configuration

TCP/IP requires manual or automatic configuration.

Administrators must understand:

- IP addresses
- Subnet masks
- Default gateways

This makes TCP/IP more complex than protocols like NetBEUI.

## 2. Security

TCP/IP has an open design, so it is less secure by default.

Extra security technologies are needed to protect communication.

Example:

- SSL/TLS encryption on websites

This encrypts traffic between:

- Client
- Web server

# Working Of TCP/IP

- User sends data (example: opens a website).
- TCP breaks the data into small packets.
- IP adds source and destination IP addresses to each packet.
- Routers send packets through the network using the destination IP address.
- Packets reach the destination system.
- TCP checks for missing or damaged packets.
- Missing packets are retransmitted if needed.
- TCP joins all packets back into original data.
- User receives the final data correctly.
