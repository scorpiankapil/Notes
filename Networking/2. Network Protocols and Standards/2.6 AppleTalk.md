## Definition

AppleTalk is a routable protocol developed by Apple and mainly used in Macintosh (Mac) environments for network communication.

It allows multiple Macintosh systems to communicate and share resources over a network.

# Use of AppleTalk

AppleTalk was used for:

- Connecting Macintosh computers
- File sharing
- Printer sharing
- Communication between Apple devices across networks

Since AppleTalk is routable, data can travel through routers to reach different networks.

# AppleTalk Phases

AppleTalk was implemented in two phases:

- Phase 1
- Phase 2

# Phase 1

## Definition

Phase 1 was designed for small workgroup networks.

## Features

- Supports smaller number of devices
- Uses nonextended networks
- One network segment can have only:
    - One network number
    - One zone

## Zone

A zone is a logical group of devices created by the network administrator.

## Example

Suppose an office has:

- 20 Macintosh computers

All systems can be placed in:

- One network number
- One zone

using AppleTalk Phase 1.

# Phase 2

## Definition

Phase 2 was designed for larger networks.

## Features

- Supports more than 200 hosts
- Uses extended networks
- One network segment can have:
    - Multiple network numbers
    - Multiple zones

Each device belongs to one zone in the network.

## Example

Suppose a company has:

- Different departments
- Hundreds of Macintosh systems

The administrator can create zones such as:

- HR Zone
- Finance Zone
- IT Zone

on the same network segment using AppleTalk Phase 2.
