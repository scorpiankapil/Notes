## Definition

IPX/SPX (Internetwork Packet Exchange / Sequenced Packet Exchange) is a protocol suite developed by Novell for NetWare networks.

It is a routable protocol used for communication between computers across networks.

Microsoft calls IPX/SPX:

- NWLink

A protocol suite means multiple protocols work together for communication.

Main protocols:

- IPX
- SPX

# Use of IPX/SPX

IPX/SPX was mainly used in:

- Novell NetWare networks
- Older enterprise networks

It was used for:

- Sending data between systems
- Routing packets across networks
- Reliable communication between devices

# IPX

## Definition

IPX (Internetwork Packet Exchange) is the protocol responsible for:

- Addressing
- Routing packets across networks

## Use of IPX

IPX helps data travel from one network to another through routers.

It identifies:

- Which network the device belongs to
- Which system should receive the data

IPX is:

- Connectionless
- Unreliable

Meaning:

- No session setup before communication
- No confirmation that packets arrived

This makes communication faster.

## Example

Suppose:

- Computer A wants to send data to Computer B on another network.

IPX:

1. Adds source and destination addresses
2. Routes the packet through routers
3. Sends packet to destination network

Even if the packet is lost, IPX itself does not retransmit it.

# SPX

## Definition

SPX (Sequenced Packet Exchange) is the protocol responsible for reliable communication.

## Use of SPX

SPX ensures:

- Packets arrive correctly
- Lost packets are retransmitted
- Errors are detected

SPX is:

- Connection-oriented
- Reliable

## Example

Suppose:

- A file is being transferred between two computers.

SPX:

1. Creates a connection/session
2. Sends packets
3. Checks whether packets arrive correctly
4. Retransmits missing packets if needed

This ensures reliable file transfer.

# IPX Address Example

An IPX address contains:

- Network ID
- MAC address

Example:

- 0BADBEEF.00904B4CC159

Where:

- 0BADBEEF = Network ID
- 00904B4CC159 = MAC address

# Frame Types

Frame type defines packet format used on the network.

Common frame types:

- 802.2
- 802.3
- ETHERNET_SNAP
- ETHERNET_II

All systems must use the same frame type for communication.
