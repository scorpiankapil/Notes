# Connection-Oriented Communication

Connection-oriented communication is a type of communication that ensures reliable delivery of data between the sender and receiver. Before sending data, the two devices first establish a connection through a process called **handshaking**. During handshaking, both devices decide communication rules such as transmission speed, ports, and how the session will begin and end. Once the connection is established, data is transferred reliably with acknowledgments and error checking. The session remains active until communication is completed properly. This type of communication is similar to a telephone call, where a connection is first established, conversation takes place, and then the call is ended properly.

### Example

Transmission Control Protocol (TCP)

---

# Connectionless Communication

Connectionless communication is a type of communication where the sender directly sends data without first establishing a connection with the receiver. The receiver does not send acknowledgment confirming whether the data was received successfully or not. Because there is no session management or handshaking, this communication is faster but less reliable. It is mainly used where speed is more important than accuracy.

### Example

User Datagram Protocol (UDP)
