# Remote Connectivity

**Remote Connectivity** is the ability to **connect to a computer or network from a different physical location** using communication technologies such as telephone lines, the Internet, or WAN technologies. It allows users to access resources, applications, and data without being physically present at the remote location.

## Why is Remote Connectivity Needed?

In today's world, people and organizations often work from different locations. Remote connectivity allows them to:

- Work from home.
- Access office files remotely.
- Connect branch offices.
- Manage servers from anywhere.
- Share information quickly.
- Communicate over long distances.

## How Remote Connectivity Works

- A **remote user** wants to access a company's network or server.
- The user connects through a **communication medium**, such as:
    - Telephone Network (PSTN)
    - Internet
    - WAN
- The connection request reaches the **company's remote access server**.
- The server **authenticates (verifies)** the user's identity (username, password, VPN credentials, etc.).
- If authentication is successful, the user is **granted access** to the company's network.
- The user can then access company resources such as:
    - Files
    - Applications
    - Databases
    - Servers
    - Printers

```
Remote User
      │
Internet / Telephone Network / WAN
      │
Authentication
      │
Company Network
      │
Company Server / Resources
```

## 1. PSTN (Public Switched Telephone Network)

The **Public Switched Telephone Network (PSTN)** is the **traditional worldwide telephone network** that uses **copper wires, fiber-optic cables, microwave links, and telephone exchanges** to provide voice communication between telephones.

It is the network used for **landline telephone services**.

### How PSTN Works

1. A user dials a telephone number.
2. The telephone converts the user's voice into electrical signals.
3. The signals are sent to the nearest **telephone exchange**.
4. The exchange identifies the destination phone number.
5. The exchange establishes a dedicated communication path (circuit) to the destination.
6. The voice signals travel through the PSTN network.
7. The destination telephone receives the signals and converts them back into sound.
8. When the call ends, the dedicated circuit is released.

## 2. Integrated Services Digital Network (ISDN)

**ISDN (Integrated Services Digital Network)** is a **digital communication standard** that allows the transmission of **voice, data, video, and fax** over traditional telephone lines.

Unlike the **PSTN**, which uses analog signals, **ISDN uses digital signals**, providing faster and higher-quality communication.

ISDN was developed to:

- Improve call quality.
- Increase data transmission speed.
- Support voice, data, video, and fax on the same telephone line.
- Provide faster Internet access than dial-up connections.

`A dial-up connection is an Internet access method that uses a standard telephone line and a modem to connect to an Internet service provider (ISP).`

### How ISDN Works

1. The user initiates a voice call, video call, or data transmission using an **ISDN phone** or **ISDN modem**.
2. The device converts the voice or data into **digital signals**.
3. The digital signals are transmitted over the **telephone line**.
4. The signals reach the nearest **ISDN exchange**.
5. The ISDN exchange identifies the destination and establishes a digital connection.
6. The digital data is routed through the ISDN network to the destination.
7. The destination device receives the digital signals.
8. The receiving device converts the digital signals back into **voice, video, or data**.
9. Communication continues until the call or data transfer is completed.
10. When the communication ends, the ISDN connection is terminated.

### ISDN Channels

An ISDN connection is made up of **logical channels**.

There are **three types of channels**:

1. B Channel (Bearer Channel)
2. D Channel (Delta/Data Channel)
3. H Channel (High-Speed Channel)

##### 1. B Channel (Bearer Channel)

The **B (Bearer) Channel** is used to **carry actual user data**.

It transfers Voice, Data, Video, Fax

- Carries actual communication.
- Bandwidth = **64 Kbps per channel**.
- Used for data transfer only.
- Multiple B channels can be combined for higher speed.
##### 2. D Channel (Delta/Data Channel)

The **D (Delta) Channel** is used for **signaling and control information**.

It does **NOT** carry user data.

It handles:

- Call setup
- Call termination
- Authentication
- Connection management
- Administrative information

##### 3. H Channel

The **H Channel** is a **high-speed channel** created by combining multiple B channels.

It is used when higher bandwidth is required.

**Types of H Channels**

|H Channel|Number of B Channels|Speed|
|---|---|---|
|**H0**|6 B Channels|**384 Kbps**|
|**H10**|23 B Channels|**1472 Kbps**|
|**H11**|24 B Channels|**1536 Kbps**|
|**H12**|30 B Channels|**1920 Kbps** (European Standard)|

### ISDN Interface

An **ISDN Interface** is the **connection method** used by devices to communicate with the **ISDN network**.

It defines **how many communication channels are available** and **the speed of data transmission**.

Different users have different communication needs.

- A home user needs only a few channels.
- A large company needs many channels.

To meet these different requirements, ISDN provides two interfaces:

1. **BRI (Basic Rate Interface)**
2. **PRI (Primary Rate Interface)**

##### 1. BRI (Basic Rate Interface)

**BRI** is designed for **home users and small businesses**.

It consists of:

- **2 B (Bearer) Channels**
- **1 D (Delta) Channel**

##### 2. PRI (Primary Rate Interface)

**PRI** is designed for **large organizations and telephone systems**.

It provides many more communication channels than BRI.

**North America & Japan**

- 23 B Channels
- 1 D Channel

**Europe, India & Many Other Countries**

- 30 B Channels
- 1 D Channel

##### BRI vs PRI
|BRI (Basic Rate Interface)|PRI (Primary Rate Interface)|
|---|---|
|Home users & small offices|Large organizations|
|2B + D|23B + D (T1) or 30B + D (E1)|
|144 Kbps|1.544 Mbps (T1) or 2.048 Mbps (E1)|
|Supports few users|Supports many users|
|Lower cost|Higher cost|

### ISDN Devices

**ISDN devices** are hardware devices used to connect computers, telephones, and other communication equipment to an **ISDN (Integrated Services Digital Network)**.

These devices enable the transmission of **voice, data, video, and fax** over an ISDN connection.

Normal telephones and computers cannot communicate directly over an ISDN network.

ISDN devices:

- Convert data into digital signals.
- Connect users to the ISDN network.
- Manage communication between devices.
