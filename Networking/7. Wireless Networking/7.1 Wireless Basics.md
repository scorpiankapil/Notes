# Wireless Basics

A **wireless network** uses **radio frequencies (RF)** to transmit data through the air instead of using physical cables. This allows devices such as laptops, smartphones, and tablets to connect to a network without being physically connected by wires.

For example, a laptop with a wireless network card can connect to a wireless network and access network resources while moving around the office.

## Wireless Modes

There are **two types of wireless network modes**:

1. **Ad Hoc Mode**
2. **Infrastructure Mode**

### 1. Ad Hoc Mode

In **Ad Hoc Mode**, wireless devices communicate directly with each other without using a wireless access point (AP).

- Peer-to-peer communication
- No access point required
- Easy & cheaper to set up
- Suitable for small temporary networks

```
Laptop A  ←→  Laptop B
```

All devices communicate directly with each other.

### 2. Infrastructure Mode

In **Infrastructure Mode**, all wireless devices communicate through a **Wireless Access Point (AP)**.

- Centralized communication
- Uses a wireless access point
- Most common wireless network mode
- Can connect wireless devices to a wired network

```
  Laptop
    │
    ▼
Wireless Access Point
    │
    ▼
Wired Network / Internet
```

The wireless client sends data to the access point, which forwards the data to the destination.

### Ad Hoc vs Infrastructure Mode

| **Ad Hoc Mode**             | **Infrastructure Mode**     |
| --------------------------- | --------------------------- |
| No Access Point required    | Requires Access Point       |
| Peer-to-peer communication  | Centralized communication   |
| Simple setup                | More secure and manageable  |
| Suitable for small networks | Suitable for large networks |
| Limited control             | Full administrative control |
