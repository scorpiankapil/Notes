# Channels

A **channel** is a specific frequency range within a wireless frequency band that is used to transmit and receive data.

Think of a channel as a **lane on a highway**. Multiple devices can use different channels to communicate without interfering with each other.

`Frequency Range`

- `A frequency range is a group of frequencies allocated for a particular type of communication.`
- `Instead of using a single frequency, wireless technologies use a range of frequencies to transmit data.`
- `Using only one frequency would cause interference when multiple devices communicate.`
- `A frequency range provides multiple frequencies so that communication can occur efficiently.`

### Example: 2.4 GHz Wi-Fi Band

The 2.4 GHz Wi-Fi band actually covers:

```
2.400 GHz to 2.4835 GHz
```

This entire range is called the **2.4 GHz frequency range**.

### Channels Within the Frequency Range

The frequency range is divided into smaller sections called **channels**.

Example:

|Channel|Frequency|
|---|---|
|1|2.412 GHz|
|6|2.437 GHz|
|11|2.462 GHz|

All these channels belong to the same 2.4 GHz frequency range.

##### Real-Life Analogy

```
Frequency Range = Highway
Channels = Lanes
Data = Cars
```
