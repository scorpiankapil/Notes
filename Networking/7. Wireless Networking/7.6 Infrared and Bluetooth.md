# Infrared and Bluetooth

These are two short-range wireless communication technologies used to connect devices **without cables**.

# Infrared (IR)

**Infrared (IR)** is a wireless communication technology that uses **infrared light waves** to transmit data between two devices.

It is commonly used in **TV remote controls, air conditioner remotes, projectors, and some computer peripherals**.

Unlike Wi-Fi or Bluetooth, Infrared requires a **direct line of sight** between the communicating devices.

1. One device sends infrared light signals.
2. The other device receives the light signals.
3. Data is transferred using these light signals.
4. Both devices must be facing each other (line of sight).

# Bluetooth

**Bluetooth** is a short-range wireless communication technology that uses **radio waves** to connect devices without cables.

It allows devices such as smartphones, laptops, headphones, keyboards, and speakers to exchange data wirelessly.

Unlike Infrared, Bluetooth **does not require line of sight**.

- Bluetooth is enabled on both devices.
- The devices discover each other.
- The devices are paired using a PIN or passkey (if required).
- A secure wireless connection is established.
- Data is exchanged using radio waves.

### Frequency Hopping

Bluetooth uses **Frequency Hopping Spread Spectrum (FHSS)**.

##### What is Frequency Hopping?

Instead of staying on one frequency, Bluetooth continuously changes frequencies.

It:

- Uses **79 channels** in the 2.4 GHz band.
- Changes frequency **1600 times per second**.

##### Why?

- Reduces interference.
- Makes communication more reliable.
- Improves security.

**Examples**

- Wireless headphones
- Wireless speakers
- Smart watches
- Wireless keyboard
- Wireless mouse
- Mobile phones
