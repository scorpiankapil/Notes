# Securing Wireless Networks

**Wireless security** is the process of protecting a wireless (WiFi) network from unauthorized access, data theft, and attacks.

Wireless security prevents unauthorized users from connecting to your network.

1. Change the default admin password.
2. Change the default SSID.
3. Disable SSID broadcasting.
4. Enable MAC address filtering.
5. Encrypt wireless traffic (prefer WPA2/WPA3).
6. Use a VPN for additional security.

## 1. Change the Admin Password

The **admin password** is used to log in to the router's management page and change its settings.

New routers come with a default username and password, such as:

```
Username: admin
Password: admin
```

If you don't change it, anyone who knows the default credentials can access your router.

- Prevents unauthorized access to router settings.
- Protects the wireless network configuration.

## 2. Change the SSID (Service Set Identifier)

**SSID (Service Set Identifier)** is the **name of a wireless (Wi-Fi) network** that identifies it.

```
Home_WiFi
Office_Network
GLA_WIFI
```

When you search for available Wi-Fi networks on your phone or laptop, the names you see are the **SSIDs**.

##### What Does "Change the SSID" Mean?

Changing the SSID means **renaming the default Wi-Fi network name** to a unique and secure name.

For example:

Default SSID:

```
TP-Link_1234
```

Changed SSID:

```
MyHomeNetwork
```

Hackers can identify the router's manufacturer from the default SSID and may use known vulnerabilities to attack it.

Changing the SSID makes it harder for attackers to identify your router.

## 3. Disable SSID Broadcasting

**SSID Broadcasting** is a feature in which a wireless router continuously advertises (broadcasts) its **SSID (Wi-Fi network name)** so that nearby devices can detect and display the network.

For example, when you turn on Wi-Fi on your phone, you see a list of available networks because routers are broadcasting their SSIDs.

Example:

```
Available Wi-Fi Networks✓ Home_WiFi✓ Office_Network✓ GLA_WIFI
```

##### What is Disable SSID Broadcasting?

**Disabling SSID Broadcasting** means configuring the wireless router to **stop advertising its Wi-Fi network name (SSID)**.

As a result, the Wi-Fi network will not appear in the list of available networks.

By hiding the SSID:

- The wireless network becomes less visible.
- Casual users cannot easily see the network.
- Users must know the exact SSID to connect.

This adds an extra layer of security.

##### Limitation

Tools such as **Kismet** can still discover hidden SSIDs.

Therefore, hiding the SSID **does not fully secure** the network.

## 4. MAC Address Filtering

**MAC Address Filtering** is a wireless security feature that allows only devices with **approved MAC addresses** to connect to a Wi-Fi network.

Each network device has a unique **MAC (Media Access Control) address**, and the router checks this address before allowing the device to connect.

##### Why is MAC Address Filtering Needed?

Without MAC filtering:

- Any device with the correct Wi-Fi password can connect.

With MAC filtering:

- Only devices whose MAC addresses are stored in the router's allowed list can connect.

This provides an additional layer of security.

## 5. Encrypt Wireless Traffic

Encryption converts readable wireless data into unreadable data while it is transmitted between the client and the access point.

Only devices with the correct encryption key can decrypt and read the data.

##### Wireless Encryption Protocols

|Protocol|Encryption|Security|
|---|---|---|
|WEP|RC4|Weak|
|WPA|TKIP|Better|
|WPA2|AES|Strong|
|WPA3|AES (Improved)|Very Strong|

## 6. Use a VPN for additional security.

A **VPN (Virtual Private Network)** is a security technology that creates a **secure, encrypted tunnel** between your device and a private network over the Internet or a wireless network.

##### Why Use a VPN?

Even if someone connects to the same Wi-Fi network or intercepts your wireless traffic, they **cannot read your data** because it is encrypted.

VPN provides an **additional layer of security** on top of Wi-Fi encryption (such as WPA2 or WPA3).

```
Laptop
   │
Connect to Wi-Fi
   │
VPN Tunnel (Encrypted)
   │
VPN Server
   │
Internet / Company Network
```
