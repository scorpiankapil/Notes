# What is Authentication?

**Authentication** is the process of verifying **who is allowed to connect** to the wireless network.


```
WiFi Password = Cyber123
```

When a user enters the correct password:

```
User → Verified     ↓Access Granted
```

This is authentication.

# What is Encryption?

**Encryption** is the process of converting readable data into unreadable data so that attackers cannot understand it.

Original Data:

```
Password = admin123
```

Encrypted Data:

```
X7$@K!9#P2
```

Only authorized devices can decrypt and read it.

# Why Do We Need Authentication and Encryption?

Without security:

```
Attacker Outside Building
         ↓
    Connects to WiFi
         ↓
    Steals Data
```

- Authentication prevents unauthorized access.
- Encryption prevents attackers from reading captured data.

## WEP (Wired Equivalent Privacy)

**WEP (Wired Equivalent Privacy)** is a wireless security protocol designed to provide security for Wi-Fi networks by using encryption to protect data transmitted over the wireless network.

WEP was the first security mechanism introduced in the **IEEE 802.11 wireless standard**.

- Uses a shared secret key.
- Uses the **RC4 stream cipher** for encryption.
- Available in:
    - 64-bit WEP
    - 128-bit WEP
- Supports authentication of wireless clients.
- Encrypts wireless traffic before transmission.

### Components Used in WEP

1. **Secret Key**

A shared password/key configured on:

- Wireless Client
- Wireless Access Point

Both devices must have the same key.

Example:

```
WEP Key = SECRET123
```

2. **Initialization Vector (IV)**

A 24-bit random value added to the secret key before encryption.

Purpose:

- Makes encryption appear different each time.
- Prevents identical packets from producing identical ciphertext.

3. **RC4 Algorithm**

WEP uses the **RC4 encryption algorithm** to encrypt data.

### Working of WEP

1. A wireless client wants to send data to the access point.
2. The client generates a **24-bit Initialization Vector (IV)**.
3. The IV is combined with the **shared WEP key**.
4. The combined value is used by the **RC4 encryption algorithm**.
5. The data is encrypted using RC4.
6. The encrypted data and IV are transmitted over the wireless network.
7. The access point receives the encrypted data and IV.
8. The access point combines the received IV with the same WEP key.
9. RC4 decrypts the data.
10. The original data is recovered and delivered to the destination.

```
WEP = Weak Security
```

Avoid using WEP unless you have very old hardware.

## WPA (Wi-Fi Protected Access)

**WPA (Wi-Fi Protected Access)** is a wireless security protocol developed to secure Wi-Fi networks and fix the security weaknesses found in WEP.

It provides stronger encryption, better authentication, and improved data protection for wireless communications.

- Stronger security than WEP.
- Uses **TKIP (Temporal Key Integrity Protocol)**.
- Dynamically changes encryption keys.
- Supports user authentication.
- Provides data integrity checking.
- More resistant to wireless attacks.

`TKIP (Temporal Key Integrity Protocol)`

- `TKIP (Temporal Key Integrity Protocol) is a security protocol used by WPA to encrypt wireless data.`
- `Its main purpose is to improve the weak security of WEP by generating a new encryption key for every data packet transmitted.`

#### Why Was WPA Needed?

WEP had many security flaws:

- Weak encryption
- Small IV size
- Easy to crack

To overcome these problems, WPA was introduced as a more secure wireless security standard.

### Types of WPA

### 1. WPA-Personal (WPA-PSK)

**WPA-Personal** uses a **Pre-Shared Key (PSK)**, which is a common password shared by all users of the wireless network.

Before connecting, every user must enter the same Wi-Fi password.

- Uses a common Wi-Fi password.
- Easy to configure.
- Suitable for homes and small offices.
- Does not require a separate authentication server.

```
Wi-Fi Name: HomeWiFi
Password: MySecureWiFi123
```

- Anyone who knows the password can connect to the network.
- Changing the password requires updating all devices.

### 3. WPA-Enterprise

**WPA-Enterprise** uses a **RADIUS (Remote Authentication Dial-In User Service) Server** to authenticate users individually.

Instead of one common password, each user receives unique credentials.

```
Unique Username
      +
Unique Password
      ↓
Verified by RADIUS Server
```

```
Kapil → kapil.patel / qw3215vad67kp
Aryan → aryan.sharma / qwertyuiop
Priya → priya.gupta / 978ghjyt456bcv
```

Most **colleges, universities, companies, and organizations** use **WPA-Enterprise**.

#### How WPA-Enterprise Works

1. The user selects the Wi-Fi network.
2. The user enters a **username and password**.
3. The wireless access point receives the credentials.
4. The access point forwards the credentials to the **RADIUS server**.
5. The RADIUS server verifies the username and password.
6. If the credentials are correct, the RADIUS server approves the user.
7. The access point grants access to the wireless network.
8. The user can now access network resources and the Internet.


## WPA2 (Wi-Fi Protected Access 2)

**WPA2 (Wi-Fi Protected Access 2)** is a wireless security protocol designed to secure Wi-Fi networks. It is the successor to WPA and provides much stronger security through the use of **AES (Advanced Encryption Standard)** encryption.

WPA2 became the standard Wi-Fi security protocol for many years because it is much more secure than both WEP and WPA.

- Uses **AES encryption**
- Much more secure than WEP and WPA
- Supports WPA2-Personal and WPA2-Enterprise
- Protects wireless data from unauthorized access
- Widely used in homes, schools, colleges, and businesses

`AES (Advanced Encryption Standard) Encryption`

- `AES (Advanced Encryption Standard) is a symmetric encryption algorithm that uses the same key for encryption and decryption of data.`
- `It was developed by NIST in 2001 and is widely used to secure wireless networks, files, and Internet communications.`
- `Symmetric encryption algorithm`
- `Uses the same key for encryption and decryption`
- `Block cipher`
- `Encrypts data in 128-bit blocks`
- `Supports key sizes:`
    - `128-bit`
    - `192-bit`
    - `256-bit`
- `Used in WPA2 and WPA3`
- `More secure than DES and 3DES`
