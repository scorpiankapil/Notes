# Dynamic Host Configuration Protocol (DHCP)

**DHCP (Dynamic Host Configuration Protocol)** is a network protocol that automatically assigns IP addresses and other network settings to devices on a network.

Instead of manually configuring TCP/IP settings, devices obtain their network configuration automatically from a DHCP server.

Instead of manually configuring:

- IP Address
- Subnet Mask
- Default Gateway
- DNS Server

DHCP does it automatically when the device starts.

#### Information Provided by DHCP

- IP Address
- Subnet Mask
- Default Gateway
- DNS Server Address
- Lease Time

#### DHCP Ports

|Device|Port|
|---|---|
|DHCP Server|67|
|DHCP Client|68|
# Working of DHCP (DORA Process)

### 1. Discover (D)

- The client joins the network.
- It broadcasts a **DHCP Discover** message.
- It asks: **"Is there any DHCP server available?"**

### 2. Offer (O)

- The DHCP server receives the request.
- It sends a **DHCP Offer** message.
- It offers an available IP address and network settings.

### 3. Request (R)

- The client accepts the offered IP address.
- It sends a **DHCP Request** message.
- It says: **"I would like to use this IP address."**

### 4. Acknowledge (A)

- The DHCP server confirms the assignment.
- It sends a **DHCP ACK (Acknowledgment)** message.
- The client can now use the assigned IP address.

**DORA**

- **D** = Discover
- **O** = Offer
- **R** = Request
- **A** = Acknowledge

1. **Discover** – The client searches for a DHCP server on the network.
2. **Offer** – The DHCP server offers an available IP address to the client.
3. **Request** – The client requests to use the offered IP address.
4. **Acknowledge (ACK)** – The DHCP server confirms and assigns the IP address to the client.
