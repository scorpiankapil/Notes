# TCP/IP Model

The TCP/IP Model is a networking model that explains how data is transmitted and communicated over networks and the internet using the TCP/IP protocol suite.

It divides network communication into different layers, where each layer performs a specific function.

It is similar to the OSI model but TCP/IP has 4 layers, instead of 7 layers in the OSI model.


## Layers of TCP/IP Model

|TCP/IP Layer|Main Function|Common Protocols|
|---|---|---|
|Application Layer|User services and network requests|HTTP, FTP, SMTP, NNTP|
|Transport Layer|Reliable/unreliable delivery|TCP, UDP|
|Internet Layer|Logical addressing and routing|IP, ARP, ICMP|
|Network Interface Layer|Physical network communication|Ethernet, Token Ring|

## Mapping of TCP/IP and OSI Model

|TCP/IP Model|OSI Model|
|---|---|
|Application Layer|Application + Presentation + Session|
|Transport Layer|Transport|
|Internet Layer|Network|
|Network Interface Layer|Data Link + Physical|

# Application Layer in TCP/IP Model

The Application Layer is the top layer of the TCP/IP model that allows users and applications to communicate over the network.

It is responsible for:

- Sending network requests
- Receiving network requests
- Providing network services to applications
- Allows communication between software and network

This layer is directly interacts with user applications or software such as Web browsers, Email applications and File transfer programs.


**Common Application Layer Protocols**

| Protocol | Purpose                 |
| -------- | ----------------------- |
| HTTP     | Transfers web pages     |
| SMTP     | Sends emails            |
| NNTP     | Transfers news articles |
| FTP      | Transfers files         |

## How It Works

1. A user uses an application like a web browser.
2. The application sends a network request.
3. The request travels through the network.
4. The receiving server accepts and processes the request.
5. The response is sent back to the user.

### HTTP

HTTP is a communication protocol used to transfer web pages and website data between a web browser and a web server.

HTTP is used for accessing and loading websites on the internet.

Port Number is 80

HTTP is stateless, meaning:
- Server does not remember previous requests automatically.

Each request is treated as:
- A new request

### SMTP

SMTP is a communication protocol used to send emails from one system or mail server to another over the internet.

It allows:

- Users to send emails
- Mail servers to transfer emails between each other

|Port|Purpose|
|---|---|
|25|Default SMTP port|
|587|Secure email submission|
|465|SMTP over SSL/TLS|

### NNTP

NNTP (Network News Transport Protocol) is a communication protocol used to distribute, read, and manage news articles and discussion groups over the internet.

- Distributes news articles
- Allows users to read discussion posts
- Manages internet newsgroups
- Transfers articles between news servers

Port Number is 119

### FTP

FTP (File Transfer Protocol) is a communication protocol used to transfer files between computers over a network or the internet.

It allows users to:

- Upload files
- Download files
- Share files between systems

| Port Number | Purpose                                 |
| ----------- | --------------------------------------- |
| Port 21     | Used for FTP control/command connection |
| Port 20     | Used for FTP data transfer              |
