# Boot Protocol

**BOOTP (Bootstrap Protocol)** is a network protocol used to automatically provide an IP address and boot information to a device when it starts up.

It was designed for **diskless workstations** and network devices that need network configuration information before they can fully boot.

A diskless workstation has:

❌ No hard disk

❌ No operating system stored locally

Therefore, it must obtain network information from a server before it can function.

# Working of BOOTP

1. The computer starts (powers on).
2. The EEPROM on network card sends a message on the network asking:  
    **"Is there any BOOTP server available?"**
3. The BOOTP server receives the request.
4. The BOOTP server sends the computer:
    - IP Address
    - Subnet Mask
    - Default Gateway
    - Boot File Information
5. The computer uses this information to configure its network settings.
6. The computer downloads the required boot files from the server.
7. The operating system loads.
8. The computer is ready to use.

**EEPROM** - A diskless workstations contains an **EEPROM (Electrically Erasable Programmable Read-Only Memory)** chip on NIC that stores a small boot program, which runs at startup, connects to the network, and requests configuration information from the BOOTP server.
