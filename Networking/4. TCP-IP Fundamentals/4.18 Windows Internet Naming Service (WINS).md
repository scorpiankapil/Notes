# Windows Internet Naming Service (WINS)

**WINS (Windows Internet Naming Service)** is a Microsoft name resolution service that translates **NetBIOS names** into **IP addresses**.

It allows Windows computers to locate and communicate with other computers on a network using computer names instead of IP addresses.

## Why WINS is Needed?

In older Microsoft networks, computers communicated using:

```
NetBIOS Names
```

Example:

```
SERVER01
FILESERVER
PRINTER01
```

Computers needed a way to convert these names into IP addresses.

WINS provided that solution.

## Working of WINS

1. A Windows computer starts and registers its **NetBIOS name** and **IP address** with the WINS server.
2. The WINS server stores this information in its database.
3. When a computer wants to communicate with another computer, it sends a query to the WINS server using the computer's NetBIOS name.
4. The WINS server searches its database for the requested computer name.
5. The WINS server returns the corresponding IP address to the client.
6. The client uses the IP address to establish communication with the destination computer.
