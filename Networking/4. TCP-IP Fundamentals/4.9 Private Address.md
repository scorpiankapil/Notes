# Private Address

**Private IP Addresses** are IP addresses used within a local network (LAN) such as a home, school, or office network. These addresses are **not accessible directly from the Internet** and can be reused in different networks.

Private IP addresses are assigned by routers or DHCP (Dynamic Host Configuration Protocol) servers to devices inside the network.

Private addresses are valid only inside local networks.

These addresses are called:

- Private Addresses
- Non-Routable Addresses

Because Internet routers do not route these addresses.

## Why Private Addresses Used? 

Private addresses help:

- Save public IP addresses
- Allow internal communication between devices
- Improve security by hiding internal devices from the Internet
- Used in homes, offices, and organizations

## Private IP Address Ranges

There are only **3 private IP ranges**:

|Class|Private Range|
|---|---|
|Class A|10.0.0.0 – 10.255.255.255|
|Class B|172.16.0.0 – 172.31.255.255|
|Class C|192.168.0.0 – 192.168.255.255|
