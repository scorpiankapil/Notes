# Default Gateway

A **Default Gateway** is the IP address of a router that a device uses to send data to devices on other networks.

When a computer wants to communicate with a device on another network or access the Internet, it sends the data to the default gateway, which then forwards it to the correct destination.

*Default Gateway = Exit Door of Your Network*

The main use of a **Default Gateway** is to allow a computer to communicate with devices that are on **different networks**.

Without a default gateway, a computer can communicate only with devices on its own network.

- Connects local networks to other networks
- Provides Internet access
- Routes packets to remote destinations
- Acts as the exit point from a local network

## Working of Default Gateway

- A device wants to send data to another device.
- It checks whether the destination is on the **same network** or a **different network** using the subnet mask.
- If the destination is on the same network, the data is sent directly to that device.
- If the destination is on a different network, the device sends the data to the **default gateway (router)**.
- The router receives the packet and checks the destination IP address.
- The router forwards the packet to the correct network or the Internet.
- The destination device receives the data and sends a response back through the router.

### Example

- PC IP: `192.168.1.10`
- Default Gateway: `192.168.1.1`
- Destination IP: `8.8.8.8`

Since `8.8.8.8` is not in the `192.168.1.0/24` network, the PC sends the packet to `192.168.1.1` (the default gateway), and the router forwards it to the Internet.
