# Network Services

A **Network Service** is a service that performs a specific function on a network and helps devices communicate, share resources, or access network features.

## 1. DHCP (Dynamic Host Configuration Protocol)

**DHCP (Dynamic Host Configuration Protocol)** is a network service that automatically assigns IP addresses and other network settings to devices on a network.

Instead of manually configuring network settings, devices receive them automatically from a DHCP server.

- Automatically assigns IP addresses.
- Assigns subnet mask.
- Assigns default gateway.
- Assigns DNS server address.
- Assigns WINS server address.
- Reduces manual configuration work.
- Prevents IP address conflicts.
- Uses a DHCP scope (range of IP addresses).

## 2. DNS (Domain Name System)

**DNS (Domain Name System)** is a protocol that translates **domain names** (such as `google.com`) into **IP addresses** (such as `142.250.183.14`).

Since humans remember names more easily than numbers, DNS allows us to use website names instead of IP addresses.

- Converts website names to IP addresses.
- Makes websites easier to access.
- Maintains a database of domain names and IP addresses.
- Used by almost all Internet applications.
- Acts like the Internet's phonebook.

## 3. WINS (Windows Internet Naming Service)

**WINS (Windows Internet Naming Service)** is a Microsoft name resolution service that translates **NetBIOS names** into **IP addresses**.

It allows Windows computers to locate and communicate with other computers on a network using computer names instead of IP addresses.

- Resolves NetBIOS names to IP addresses.
- Mainly used in older Microsoft networks.
- Maintains a database of computer names.
- Allows computers to find each other using names.
- Similar to DNS but works with NetBIOS names.

## 4. NAT (Network Address Translation)

**NAT (Network Address Translation)** is a network service that converts **private IP addresses** into **public IP addresses** (and vice versa) so devices on a local network can communicate with the Internet.

It allows multiple devices to share a single public IP address.

- Converts private IPs to public IPs.
- Hides internal network devices.
- Improves security.
- Allows private networks to access the Internet.
- Conserves public IP addresses.
- Commonly implemented on routers and firewalls.

## 5. PAT (Port Address Translation)

PAT is a form of NAT that allows multiple private devices to share a single public IP address by using different port numbers.

- Also called NAT Overloading.
- Many devices share one public IP.
- Uses port numbers to identify devices.
- Maintains a PAT table.
- Most home routers use PAT.
- Saves public IP addresses.

**Example:** 
```
PC1 → 192.168.1.10:1050
PC2 → 192.168.1.20:1051

Both use:

49.205.100.50
```

## 6. SNAT (Secure Network Address Translation)

**SNAT (Source Network Address Translation)** is a type of NAT that changes the **source IP address** of outgoing packets before they are sent to another network or the Internet.

- Allows private IP addresses to communicate with the Internet.
- Hides internal IP addresses from external networks.
- Enables multiple devices to access the Internet through a public IP.
- SNAT replaces the private source IP with a public IP.

## 7. ICS (Internet Connection Sharing)

**ICS (Internet Connection Sharing)** is a feature in Windows that allows one computer with an Internet connection to share that connection with other computers on a local network.

The computer connected to the Internet acts like a small router for other devices.

- Shares an Internet connection with other devices
- Acts as a mini router
- Provides basic NAT functionality
- Allows multiple devices to access the Internet through one connection

## 8. SMB (Server Message Block) / CIFS

**SMB (Server Message Block)** is a network protocol used for **file sharing, printer sharing, and access to shared resources** between computers on a network.

It is commonly used in Windows environments to allow users to access files, folders, and printers on remote computers as if they were local.

- Share files and folders
- Share printers
- Access remote resources
- Works over TCP/IP.
- Supports authentication and authorization.
- Communicate with file servers

## 9. NFS (Network File System)

**NFS (Network File System)** is a network protocol that allows users to access files and folders on a remote computer as if they were stored on their local machine.

It is commonly used in **Linux and UNIX environments** for file sharing.

- Used in Linux/UNIX environments.
- Allows remote file access.
- Appears like local storage.
- Platform independent.
- Uses VFS (Virtual File System).
- Equivalent of SMB in Linux.

## 10. AFP (Apple Filing Protocol)

**AFP (Apple Filing Protocol)** is a network file-sharing protocol developed by Apple that allows **Mac computers** to share files, folders, and network resources over a network.

It was designed primarily for communication between Apple devices.

- Used in Apple/Mac environments.
- Provides file sharing.
- Supports remote file access.
- Provides access control and security.
- Originally used AppleTalk.
- Modern versions run over TCP/IP.

## 11. Samba

**Samba** is an open-source software suite that allows **Linux and UNIX systems** to share files, folders, and printers with **Windows systems** using the SMB protocol.

It acts as a bridge between Linux and Windows networks.

- Bridges Windows and Linux systems.
- Allows Windows clients to access Linux file shares.
- Allows printer sharing.
- Provides authentication services.
- Uses SMB protocol.
- Makes Linux servers appear like Windows servers.

## 12. Zero Configuration Networking (ZeroConfig)

**ZeroConfig** is a network service that automatically discovers and configures network services with little or no administrator involvement.

- Automatic device configuration.
- Automatically discovers services.
- No manual setup required.
- Reduces administration effort.
- Common in home and IoT networks.
- Plug-and-play networking experience.
