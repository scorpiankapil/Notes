# TCP/IP Ports

A **TCP/IP Port** is a logical communication endpoint used by TCP and UDP to identify a specific application or service running on a device.

While an **IP address** identifies a device on the network, a **port number** identifies the application or service on that device.

Think of it like:

- **IP Address = House Address 🏠**
- **Port Number = Room Number 🚪**

## Why are Ports needed?

Ports are needed because multiple network application or services can run on the same computer at the same time, and the operating system needs a way to know which application should receive each incoming packet.

Suppose a server has:

- A website running
- An email service running
- An FTP service running

All services use the same IP address. Ports help the operating system determine which service should receive incoming data.

## Common TCP/IP Ports

| Port | Protocol | Purpose                    |
| ---- | -------- | -------------------------- |
| 20   | FTP-DATA | FTP Data Transfer          |
| 21   | FTP      | FTP Control                |
| 22   | SSH      | Secure Remote Login        |
| 23   | TELNET   | Remote Login (Unencrypted) |
| 25   | SMTP     | Sending Email              |
| 53   | DNS      | Name Resolution            |
| 69   | TFTP     | Simple File Transfer       |
| 80   | HTTP     | Web Browsing               |
| 110  | POP3     | Receiving Email            |
| 119  | NNTP     | News Groups                |
| 123  | NTP      | Time Synchronization       |
| 143  | IMAP4    | Email Access               |
| 443  | HTTPS    | Secure Web Browsing        |
