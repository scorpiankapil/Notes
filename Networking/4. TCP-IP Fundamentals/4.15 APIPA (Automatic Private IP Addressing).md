# APIPA (Automatic Private IP Addressing)

**APIPA (Automatic Private IP Addressing)** is a feature that automatically assigns an IP address to a device when a DHCP server is unavailable or cannot be reached.

It allows devices on the same local network to communicate with each other even when they cannot obtain an IP address from DHCP.

**APIPA Range**

```
169.254.0.1 to 169.254.255.254
```

 **Default Subnet Mask**

```
255.255.0.0
```

# Working of APIPA

1. The computer starts (boots up).
2. The computer is configured to obtain an IP address automatically using DHCP.
3. The computer sends a **DHCP Discover** message to find a DHCP server.
4. The computer waits for a response from the DHCP server.
5. If no DHCP server responds, the computer assumes DHCP is unavailable.
6. Windows automatically generates an IP address from the APIPA range:
    
    ```
    169.254.x.x
    ```
    
7. The computer checks to make sure the generated IP address is not already being used by another device.
8. If the address is unique, the computer assigns the APIPA address to itself.
9. The computer also assigns the default APIPA subnet mask:
    
    ```
    255.255.0.0
    ```
    
10. No Default Gateway is assigned.
11. The computer can now communicate with other devices that also have APIPA addresses on the same local network.
12. The computer cannot access:
    - Internet
    - Other networks
    - Remote servers
13. If a DHCP server becomes available, the APIPA address is replaced with a valid DHCP-assigned IP address.
