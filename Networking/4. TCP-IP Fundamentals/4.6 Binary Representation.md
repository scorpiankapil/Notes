# Understanding Binary

Computers understand only two values:

- **0 = OFF**
- **1 = ON**

This number system is called **Binary** (Base-2).

In networking, IP addresses are actually stored in binary form.

Example:

```
Decimal IP: 192.168.1.15

Binary IP: 11000000.10101000.00000001.00001111
```

## What is Bit?

A **Bit** (Binary Bit) is the smallest unit of data.

A bit can have only:

```
0 or 1
```

## What is Octet?

An **Octet** is a group of 8 bits.

Example:

```
11000000
```

This is one octet.

Since an IPv4 address has 4 octets:

```
8 bits × 4 = 32 bits
```

## Binary Values of Each Bit Position

When reading an octet from left to right:

|Bit Position|8|7|6|5|4|3|2|1|
|---|---|---|---|---|---|---|---|---|
|Value|128|64|32|16|8|4|2|1|

- Leftmost bit = Most Significant Bit (MSB)
- Rightmost bit = Least Significant Bit (LSB)

## How Binary Works

- 1 = Include the value
- 0 = Ignore the value

###  Convert Binary to Decimal
#### Example 1

Binary:

```
11000000
```

| 128 | 64  | 32  | 16  | 8   | 4   | 2   | 1   |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1   | 1   | 0   | 0   | 0   | 0   | 0   | 0   |

Calculation:

```
128 + 64 = 192
```

Answer:

```
11000000 = 192
```

#### Example 2

Binary:

```
00001111
```

|128|64|32|16|8|4|2|1|
|---|---|---|---|---|---|---|---|
|0|0|0|0|1|1|1|1|

Calculation:

```
8 + 4 + 2 + 1= 15
```

Answer:

```
00001111 = 15
```

### Convert Decimal to Binary

#### Example 1

Find values that add up to 192.

```
128 + 64 = 192
```

Turn ON those bits:

|128|64|32|16|8|4|2|1|
|---|---|---|---|---|---|---|---|
|1|1|0|0|0|0|0|0|

Answer:

```
192 = 11000000
```

#### Example 2

Find values that add up to 168.

```
128 + 32 + 8= 168
```

|128|64|32|16|8|4|2|1|
|---|---|---|---|---|---|---|---|
|1|0|1|0|1|0|0|0|

Answer:

```
168 = 10101000
```

#### Example 3

```
8 + 4 + 2 + 1= 15
```

|128|64|32|16|8|4|2|1|
|---|---|---|---|---|---|---|---|
|0|0|0|0|1|1|1|1|

Answer:

```
15 = 00001111
```


## IP Address Binary Example

IP Address:

```
192.168.1.15
```

Conversion:

```
192 = 11000000168 = 101010001   = 0000000115  = 00001111
```

Final Binary Form:

```
11000000.10101000.00000001.00001111
```
