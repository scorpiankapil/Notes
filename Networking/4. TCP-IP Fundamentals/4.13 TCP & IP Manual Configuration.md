# Manual Configuration

**Manual Configuration of TCP/IP** is the process of manually assigning network settings to a device instead of receiving them automatically from a DHCP server.

The user or administrator enters all required network information manually.

It is also called Static Configuration

## Information Required

When configuring TCP/IP manually, you typically enter:

- **IP Address** – Unique address of the device
- **Subnet Mask** – Identifies the network and host portions
- **Default Gateway** – Router used to access other networks
- **DNS Server Address** – Resolves domain names into IP addresses

### Example

|Setting|Value|
|---|---|
|IP Address|192.168.1.10|
|Subnet Mask|255.255.255.0|
|Default Gateway|192.168.1.1|
|DNS Server|8.8.8.8|
