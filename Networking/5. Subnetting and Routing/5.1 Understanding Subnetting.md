# Subnetting 

**Subnetting** is the process of dividing one large network into multiple smaller networks called **subnets**.

##### Imagine a Big School

*Suppose your school has **1000 students**.*

*If all 1000 students are placed in **one giant classroom**, what happens?*

- *Too much noise*
- *Difficult to manage*
- *Teacher can't control everyone*
- *Everyone hears every announcement*

```
One Big Classroom
────────────────────
1000 Students
────────────────────
```

*So what does the school do?*

*It divides students into:*

```
Class A = 250 students
Class B = 250 students
Class C = 250 students
Class D = 250 students
```

*Now management becomes easier.*

*This is exactly what subnetting does.*

# How Subnetting Works

Subnetting works by **borrowing bits from the Host ID portion of an IP address and adding them to the Network ID portion**. This creates multiple smaller networks (subnets) from one large network.

## Step 1: Start with a Network

Suppose we have:

```
IP Address: 192.168.1.0
Subnet Mask: 255.255.255.0
CIDR: /24
```

Structure:

|Network ID|Host ID|
|---|---|
|192.168.1|0-255|

This network can have **254 hosts**.

## Step 2: Borrow Host Bits

Original:

```
/24
```

This means:

```
24 Network Bits8 Host Bits
```

Now borrow **2 host bits**:

```
/26
```

New structure:

```
26 Network Bits6 Host Bits
```

The borrowed bits are now used to create subnets.

## Step 3: Create Subnets

Borrowed bits = 2

Number of subnets:

22=42^2=422=4

So the original network is divided into **4 smaller networks**.

## Step 4: Divide the IP Range

Original range:

```
192.168.1.0 - 192.168.1.255
```

After subnetting:

|Subnet|Range|
|---|---|
|Subnet 1|192.168.1.0 - 192.168.1.63|
|Subnet 2|192.168.1.64 - 192.168.1.127|
|Subnet 3|192.168.1.128 - 192.168.1.191|
|Subnet 4|192.168.1.192 - 192.168.1.255|

Each range becomes a separate subnet.

## Step 5: Hosts in Each Subnet

Remaining host bits = 6

Hosts per subnet:

26−2=622^6-2=6226−2=62

Each subnet can support **62 devices**.
