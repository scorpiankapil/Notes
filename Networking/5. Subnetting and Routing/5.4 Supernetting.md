# Supernetting

**Supernetting** is the process of combining multiple smaller networks into one larger network by borrowing bits from the network portion and giving them back to the host portion.

It is the opposite of **subnetting**.

- **Subnetting** → One large network ➝ Multiple smaller networks
- **Supernetting** → Multiple smaller networks ➝ One large network

## Why We Need Supernetting?

- Combines multiple small networks into one large network.
- Reduces the number of routes stored in a router.
- Makes routing tables smaller.
- Saves router memory.
- Helps routers find routes faster.
- Reduces the amount of routing information exchanged between routers.
- Improves overall network performance.
- Makes network management easier.
- Allows route summarization (combining multiple routes into one route).
- Helps large networks and ISPs handle routing more efficiently.
- Reduces the workload on routers.
- One summarized route can replace many individual routes.
