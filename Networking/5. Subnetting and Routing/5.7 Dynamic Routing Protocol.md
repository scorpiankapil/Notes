# Dynamic Routing Protocol

**Dynamic Routing Protocols** are protocols that allow routers to automatically share routing information with each other and update their routing tables without manual configuration.

- Automatically share routing information between routers.
- Reduce manual work for network administrators.
- Automatically learn new routes.
- Automatically update routing tables when network changes occur.
- Make managing large networks easier.
- Help routers find the best path to a destination network.

## What is Convergence?

**Convergence** is the process where all routers have shared their routing information and every router has an updated and consistent routing table.

### Example

```
Router A knows:
192.168.1.0

Router B knows:
192.168.2.0

Router C knows:
192.168.3.0
```

After sharing routes:

```
Router A knows:
192.168.1.0
192.168.2.0
192.168.3.0

Router B knows:
192.168.1.0
192.168.2.0
192.168.3.0

Router C knows:
192.168.1.0
192.168.2.0
192.168.3.0
```

# Distance Vector

Distance Vector Routing Protocols determine the best route based on the lowest hop count (number of routers between source and destination).

**Hop Count** is the number of routers a packet must pass through to reach the destination.

Example:

```
PC A
  ↓
Router A
  ↓
Router B
  ↓
Router C
  ↓
PC B
```

Hop Count:

```
Router A → Router B = 1 Hop
Router B → Router C = 2 Hops
```

Total:

```
2 Hops
```

# RIP/RIPv2 (Routing Information Protocol)

The **Routing Information Protocol (RIP)** is a distance vector protocol and is responsible for sharing its routing table information with neighboring routers by broadcasting the information over UDP every 30 seconds. This broadcasting of the routing table is known as advertising

# Autonomous System (AS)

An **Autonomous System (AS)** is a collection of networks managed by a single organization.

Examples:

- ISP Network
- Google Network
- Microsoft Network

Each AS has a unique **ASN (Autonomous System Number)**.

# IGRP (Interior Gateway Routing Protocol)

**IGRP (Interior Gateway Routing Protocol)** is a **Distance Vector Routing Protocol** developed by Cisco to help routers exchange routing information and find the best path within a network.

It was created to overcome some limitations of RIP, especially in larger networks.

- Supports larger networks
- Uses multiple metrics to find the best route
- Provides better performance than RIP

# BGP (Border Gateway Protocol)

**BGP (Border Gateway Protocol)** is a routing protocol used to exchange routing information **between different Autonomous Systems (AS)** on the Internet.

It is known as the **routing protocol of the Internet** because it helps routers decide the best path for data to travel between different organizations, ISPs, and countries.

# RIP vs. BGP

| **RIP (Routing Information Protocol)**  | **BGP (Border Gateway Protocol)**                    |
| --------------------------------------- | ---------------------------------------------------- |
| Distance Vector Routing Protocol        | Path Vector Routing Protocol                         |
| Used in small to medium-sized networks  | Used on the Internet and large networks              |
| Selects routes based on hop count       | Selects routes based on AS Path and routing policies |
| Maximum hop count is 15                 | No practical hop-count limit                         |
| Easy to configure and manage            | More complex to configure and manage                 |
| Uses UDP Port 520                       | Uses TCP Port 179                                    |
| Sends routing updates every 30 seconds  | Sends updates only when network changes occur        |
| Less scalable                           | Highly scalable                                      |
| Slower convergence                      | More stable and reliable                             |
| Used for routing within an organization | Used for routing between Autonomous Systems (AS)     |

# Link State Routing Protocol

A **Link State Routing Protocol** is a dynamic routing protocol in which each router builds a complete map (topology) of the network and calculates the best path to every destination.

Unlike Distance Vector protocols, routers do not rely only on information from neighbor routers. Instead, they learn about the entire network.

**Network Topology** is a complete map of all routers, networks, and links in the network.

## How Link State Works

1. Each router discovers its neighboring routers.
2. The router checks the status of its links (connections).
3. The router shares this link information with all other routers in the network.
4. Every router builds a complete map of the network.
5. Each router calculates the shortest and best path to every destination.
6. The routing table is updated with the best routes.
7. If a link goes down, all routers are informed immediately and calculate a new path.

# Distance Vector vs Link State

|Distance Vector Routing|Link State Routing|
|---|---|
|Knows only about neighboring routers.|Knows the entire network topology.|
|Shares the complete routing table with neighbors.|Shares link-state information with all routers.|
|Uses **hop count** or distance metrics to select routes.|Uses the shortest path algorithm to select routes.|
|Slower convergence.|Faster convergence.|
|More prone to routing loops.|Less prone to routing loops.|
|May take time to detect link failures.|Detects link failures quickly.|
|Uses less CPU and memory.|Uses more CPU and memory.|
|Easier to configure.|More complex to configure.|
|Suitable for small networks.|Suitable for large networks.|
|Example: **RIP, IGRP**|Example: **OSPF, IS-IS**|

## OSPF (Open Shortest Path First)

**OSPF** is a Link State routing protocol that calculates the shortest path to a destination using complete network topology information.

## IS-IS (Intermediate System to Intermediate System)

**IS-IS** is a Link State routing protocol used inside a network to share routing information.

# Hybrid Routing Protocols

**Hybrid Routing Protocols** are routing protocols that combine features of both **Distance Vector** and **Link State** routing protocols.

They use the simplicity of Distance Vector routing and the fast convergence and efficiency of Link State routing.
