# Routing 

**Routing** is the process of finding the best path and sending data from one network to another network using a **router**.

## Why is Routing Needed?

### Same Network

If two computers are on the same network, they can communicate directly.

Example:

```
PC1 = 192.168.1.10
PC2 = 192.168.1.20
```

Both belong to:

```
192.168.1.0/24
```

So PC1 sends data directly to PC2.

**No router is needed.**

### Different Networks

Example:

```
PC1 = 192.168.1.10
PC2 = 192.168.3.20
```

PC1 belongs to:

```
192.168.1.0
```

PC2 belongs to:

```
192.168.3.0
```

These are different networks.

So PC1 cannot send data directly.

A **router is needed**.

---

# How Routing Works

### 1. A source computer wants to send data to another computer.

Example:

```
Source:192.168.1.10
Destination:192.168.3.20
```

### 2. The source computer checks whether the destination is on the same network.

Example:

```
Source Network:192.168.1.0
Destination Network:192.168.3.0
```

Both networks are different.

### 3. Since the destination is on another network, the source computer sends the packet to its default gateway (router).

Example:

```
Default Gateway:192.168.1.1
```

### 4. The router receives the packet.

### 5. The router examines the destination IP address.

Example:

```
Destination:192.168.3.20
```

### 6. The router checks its routing table.

The routing table contains information about:

- Destination networks
- gateways
- Interfaces

### 7. The router searches for the destination network in the routing table.

Example:

```
192.168.3.0
```

### 8. If a matching route is found, the router determines:

- Where to send the packet (Gateway/Next Hop)
- Which interface to use

### 9. The router forwards the packet to the next router or destination network.

Example:

```
Router A   
   ↓
Router B
```

### 10. Each router repeats the same process.

- Receives packet
- Checks destination IP
- Checks routing table
- Forwards packet

### 11. The final router reaches the destination network.

Example:

```
192.168.3.0
```

### 12. The final router delivers the packet directly to the destination computer.

Example:

```
192.168.3.20
```

### 13. The destination computer receives the data.

# Complete Example

```
PC A  
192.168.1.10  
│  
▼  
Router A  
192.168.1.1  
192.168.2.1  
│  
▼  
Router B  
192.168.2.2  
192.168.3.1  
│  
▼  
PC B  
192.168.3.20
```

Packet Flow:

```
PC A
  ↓
Default Gateway
(Router A)
  ↓
Routing Table Lookup
  ↓
Router B
  ↓
Destination Network
  ↓
PC B
```

# What Happens If No Route Exists?

1. A router receives a packet.
2. The router checks its routing table.
3. The router searches for the destination network.
4. No matching route is found in the routing table.
5. The router does not know where to send the packet.
6. The packet is dropped (discarded).
7. The router may generate an ICMP error message.
8. An **ICMP Destination Unreachable** message is sent back to the source device.
9. The source device receives the error message.
10. Communication with the destination network fails.
