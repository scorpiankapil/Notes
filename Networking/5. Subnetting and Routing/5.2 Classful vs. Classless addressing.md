# Classful vs. Classless addressing

Both are methods of assigning and managing IP addresses.

## 1. Classful Addressing

**Classful Addressing** is the older method of IP addressing where IP addresses are divided into fixed classes (A, B, C, D, E).

Each class has a predefined subnet mask.

### Default Masks

|Class|Default Subnet Mask|
|---|---|
|A|255.0.0.0 (/8)|
|B|255.255.0.0 (/16)|
|C|255.255.255.0 (/24)|

### Example

```
10.0.0.0
```

Automatically considered:

```
Class A → /8
```

## Problems with Classful Addressing

- Wastes IP addresses
- Inflexible
- Cannot create custom subnet sizes

**Example:**

A company needs only 500 IP addresses.

Class A provides:

```
16 million+ IP addresses
```

Most addresses are wasted.

## 2. Classless Addressing (CIDR)

**Classless Addressing** is the modern method of IP addressing that uses **CIDR notation** to define the network size.

It does not depend on Classes A, B, or C.

### Example

```
192.168.1.0/26
```

Here:

```
/26
```

defines the network size.

## Advantages of Classless Addressing

- Better IP address utilization
- Flexible subnet sizes
- Supports subnetting
- Reduces IP wastage
- More efficient routing

### Example

Suppose a company needs 60 IP addresses.

### Classful

Must use:

```
192.168.1.0/24
```

Hosts:

```
254
```

Many addresses are wasted.

### Classless

Can use:

```
192.168.1.0/26
```

Hosts:

```
62
```

Almost perfect fit.


# Difference Between Classful and Classless Addressing

|Classful Addressing|Classless Addressing (CIDR)|
|---|---|
|Uses predefined classes (A, B, C).|Does not use predefined classes.|
|Uses fixed subnet masks.|Uses flexible subnet masks.|
|Network size is determined by the class.|Network size is determined by CIDR notation (/8, /16, /24, /26, etc.).|
|Wastes more IP addresses.|Uses IP addresses efficiently.|
|Limited subnetting capability.|Supports flexible subnetting.|
|Older addressing method.|Modern addressing method.|
|Example: `172.16.0.0` is automatically Class B (/16).|Example: `172.16.0.0/20` or `172.16.0.0/26` can be used as needed.|

Classful addressing uses fixed network classes and subnet masks, while Classless addressing (CIDR) uses flexible subnet masks to create networks of any required size.
