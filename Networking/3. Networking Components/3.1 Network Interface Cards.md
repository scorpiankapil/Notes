# Network Interface Cards

A Network Interface Card (NIC) is a hardware device that allows a computer or device to connect and communicate with a network.

It acts as an interface between the computer and the network by sending and receiving data. A NIC can be built into the motherboard or installed separately as an expansion card.

It is responsible for sending and receiving data from to the network.

### Working of NIC

1. The computer sends data to the NIC.
2. The NIC converts the data into electrical signals (Ethernet) or radio signals (Wi-Fi).
3. The NIC adds the device’s unique **MAC address** to the data frame.
4. The data is transmitted through the network cable or wireless medium.
5. When data comes from the network, the NIC receives the signals.
6. The NIC converts the signals back into digital data.
7. It checks whether the destination MAC address matches the device.
8. If matched, the NIC forwards the data to the operating system and applications.

The NIC converts:

- Computer data → Electrical signals (while sending)
- Electrical signals → Computer data (while receiving)

### Types of NIC

## 1. Integrated NIC

An **Integrated NIC** is a network interface card built directly into the computer’s motherboard. Most modern computers and laptops come with an integrated NIC by default.
### Example

Built-in Ethernet or Wi-Fi adapter in laptops.

## 2. Add-on NIC

An **Add-on NIC** is a separate network card installed into an expansion slot of the computer, such as PCI or PCIe.
### Example

PCIe Ethernet card or external USB Wi-Fi adapter.

## Expansion Bus Architectures

These are slots used to install network cards inside computers.

|Bus Type|Full Form|Speed / Features|
|---|---|---|
|ISA|Industry Standard Architecture|Old technology, 8 MHz, supports 8-bit or 16-bit cards|
|MCA|Microchannel Architecture|IBM technology, 32-bit, 10 MHz|
|VESA / VLB|Video Electronics Standards Association|32-bit, around 33 MHz|
|EISA|Extended Industry Standard Architecture|Upgrade of ISA, 32-bit, 8 MHz|
|PCI|Peripheral Component Interconnect|Most popular, 32-bit/64-bit, 33 MHz|
|AGP|Advanced Graphics Port|Mainly for graphics cards, 66 MHz|
|PCMCIA|Personal Computer Memory Card Industry Association|Used in laptops, 16-bit, 33 MHz|

## NIC Diagnosis Steps

If a **NIC (Network Interface Card)** is not working, the user can perform these diagnosis steps:

1. Check whether the Ethernet cable or Wi-Fi connection is properly connected.
2. Verify if NIC indicator LEDs are blinking or showing activity.
3. Restart the computer and networking device (router/switch).
4. Check if the NIC is enabled in the operating system settings or Device Manager.
5. Update or reinstall the NIC drivers.
6. Use commands like:
    - `ipconfig` (Windows)
    - `ifconfig` or `ip a` (Linux)  
        to check network configuration.
7. Ping the local gateway or another device to test connectivity.
8. Check whether the NIC is detected in BIOS/UEFI.
9. Try using another cable, switch port, or network.
10. If the NIC still does not work, test with an external USB NIC or replace the NIC hardware.
