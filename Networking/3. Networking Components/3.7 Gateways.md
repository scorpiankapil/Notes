# Gateways

A gateway is a network device that connects two different networks and allows communication between them.

It translates data from one format or protocol to another format or protocol.

It acts as an entry and exit point for data traveling between networks.

- Connects different networks
- Routes traffic between networks
- Translates communication protocols
- Controls network access
- Acts as a bridge between systems

### Working of Gateways

- A system sends data to another different network/system.
- The gateway receives the packet.
- The gateway removes the original packet information.
- It translates/reformats the data into a format understood by the destination network.
- The gateway rebuilds the packet.
- The translated packet is sent to the destination system.

## Default Gateway

When you configure TCP/IP on a computer, you usually enter:

- IP Address
- Subnet Mask
- Default Gateway

Here:
- The “default gateway” is normally the IP address of the router on your network.

Suppose your computer wants to send data:

- Inside same network → directly sends data
- Outside network/Internet → sends data to router

That router is called:
- Default Gateway

### Example

Your PC:
- IP Address → 192.168.1.10

Router:
- IP Address → 192.168.1.1

Then:
- Default Gateway = 192.168.1.1
