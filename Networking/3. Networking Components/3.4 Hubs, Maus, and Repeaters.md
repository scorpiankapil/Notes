
Once you have the network card inserted into the computer system or network device, you will next need to connect each of the systems together using devices such as hubs, repeaters, or MAUs.
# Hubs

A **Hub** is a basic networking device used to connect multiple computers or devices in a Local Area Network (LAN).

It receives data from one device and broadcasts it to all connected devices without checking the destination address.

- Works at Physical Layer (Layer 1) of OSI model
- Does not filter data
- Broadcasts data to all ports
- Simple and inexpensive
- Causes more network traffic and collisions
### Working of Hub

1. A device sends data to the hub.
2. The hub receives the signal.
3. The hub forwards the data to every connected device.
4. The destination device accepts the data, while others ignore it.

## Types of Hubs

### 1. Passive Hub

A Passive Hub simply receives data signals and forwards them to all connected devices without strengthening or modifying the signal. It does not require electrical power for signal amplification.

### 2. Active Hub

An Active Hub receives signals, amplifies or regenerates them, and then forwards them to connected devices. It helps improve signal strength and network communication over longer distances.

### 3. Hybrid Hub

A Hybrid Hub is a networking hub that can connect different types of network cables, devices, or network architectures together.

It is used when a network contains multiple communication technologies or media types.

- Connects different network standards
- Supports multiple cable types
- Allows communication between different network segments

# MAUs

A MAU (Multistation Access Unit) is a networking device used in Token Ring networks to connect multiple computers together.

It works similarly to a hub but is specially designed for Token Ring architecture developed by IBM.

- Connects devices in a Token Ring network
- Manages token passing between devices
- Maintains network communication
- Bypasses faulty devices automatically

### Working of MAU

1. All computers are connected to the MAU.
2. The MAU logically forms a ring between connected devices.
3. A special packet called a token continuously circulates in the network.
4. A computer can send data only when it receives the token.
5. After sending the data, the token is released to the next device.
6. The MAU passes the token and data from one device to another in sequence.
7. If a device fails, the MAU automatically bypasses that device to keep the network running.

# Repeater

A Repeater is a networking device used to regenerate and amplify weak network signals so that data can travel longer distances without loss.

It receives weak or damaged signals, strengthens them, and retransmits them.

- Amplifies weak signals
- Regenerates network data
- Extends network distance
- Reduces signal loss
- Works at Physical Layer (Layer 1) of OSI model

### Working of Repeater

1. A weak network signal reaches the repeater.
2. The repeater receives the signal from the transmission media.
3. It regenerates and amplifies the weak or damaged signal.
4. The repeater removes noise and restores signal strength.
5. The strengthened signal is retransmitted to the next network segment.
6. This process helps data travel longer distances without signal loss.
