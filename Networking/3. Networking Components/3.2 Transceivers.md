# Transceivers

A transceiver is a part of the network interface that is responsible for transmitting and receiving the signal across the network media (cables/wireless).

The word transceiver comes from:

- Transmitter + Receiver

### Working of Transceiver

When data travels on the network cable:

1. The transceiver receives the electrical signal
2. Checks whether the data is meant for the local system
3. If yes → sends data to the computer for processing
4. If no → discards the data

# Types of Transceivers

## 1. Onboard Transceivers

Onboard transceivers are built directly into the NIC (Network Interface Card).

The connector is present on the back of the NIC itself.

### Common Connectors

- RJ-45 → Twisted-pair cable
- BNC → Thinnet coaxial cable

## 2. External Transceivers

External transceivers are separate devices connected externally to the NIC.

They connect using:

- AUI (Attachment Unit Interface) connector
- Also called DIX (Digital-Intel-Xerox) connector


# Difference Between NIC and Transceiver

|NIC (Network Interface Card)|Transceiver|
|---|---|
|A hardware card that connects a computer to a network|A device/component that sends and receives signals|
|Provides full network connectivity to the system|Mainly handles signal transmission and reception|
|Has a MAC address|Usually does not manage MAC addressing|
|Installed internally or externally in a computer|Can be built inside NICs, routers, or switches|
|Converts data and communicates with network|Converts signals between transmission media|
|Used to connect devices to networks|Used to transmit and receive network signals|
|Example: Ethernet card, Wi-Fi adapter|Example: SFP module, radio transceiver|

An **SFP module** is a small removable device used in switches and routers to send and receive network data through fiber optic or Ethernet cables. It helps connect network devices over short or long distances.

# Transmission Modes or Communication Modes

Communication modes define how devices send and receive data on a network.

## **1. Simplex**

Simplex communication allows data transfer in only one direction.

A device can:

- Only send  
    or
- Only receive

but cannot do both.

### Example

- Keyboard → sends data only
- Monitor → receives data only
- Radio broadcasting

## **2. Half Duplex**

Half duplex communication allows data transfer in both directions, but not at the same time.

A device can:

- Send data
- Receive data

but only one operation happens at one time.

### Example

- Walkie-talkie

Only one person can talk at a time.

## **3. Full Duplex**

Full duplex communication allows sending and receiving data at the same time.

Both devices can communicate simultaneously.

Full duplex uses:

- All four wire pairs in Ethernet communication

### Example

- Telephone call
- Modern Ethernet networks
