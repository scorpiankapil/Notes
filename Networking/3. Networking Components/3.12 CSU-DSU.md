# CSU/DSU

CSU/DSU is a networking device used to connect a router to a leased line or WAN connection provided by an ISP or telecom company.

It helps routers communicate properly over long-distance digital communication lines.

*A leased communication line is a dedicated private network connection rented from a telecom or internet service provider for continuous communication between two locations.*

*It is called “leased” because the organization pays the provider to use the line permanently or for a fixed period.*

- **CSU** → Channel Service Unit
- **DSU** → Data Service Unit

Both work together as one device.

Imagine:
- Your router speaks one “language”
- The telecom leased line speaks another “language”

The CSU/DSU acts like a translator and connector between them.


## Functions of CSU/DSU

- Connects the router to a leased communication line.
- Converts and formats data for WAN transmission.
- Maintains proper digital signal communication.
- Detects transmission errors and monitors line quality.
- Synchronizes data transfer between connected networks.

## Working of CSU/DSU

1. The router sends digital data to the CSU/DSU.
2. CSU/DSU prepares and formats the data for transmission.
3. The data travels through the leased telecom line.
4. The receiving CSU/DSU converts the signal back for the destination router.
