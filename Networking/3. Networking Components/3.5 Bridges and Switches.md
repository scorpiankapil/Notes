# Bridge

A Bridge is a networking device used to connect and divide two or more network segments in a Local Area Network (LAN).

It works at the Data Link Layer (Layer 2) of the OSI model and uses MAC addresses to forward data only to the correct destination segment.

- Works at OSI Layer 2 (Data Link Layer)
- Uses MAC addresses for forwarding data
- Divides network into multiple segments
- Reduces network traffic and congestion
- Uses a bridging table to store MAC addresses

### Working of Bridge

1. A device sends data on the network.
2. The bridge receives the frame/data.
3. The bridge checks the destination MAC address.
4. The bridge looks in its bridging table to find the destination segment.
5. If the MAC address exists in the table:
    - The bridge forwards data only to that specific segment.
6. If the MAC address is unknown:
    - The bridge forwards data to all segments except the source segment.
7. The bridge learns MAC addresses from incoming traffic and stores them in the bridging table.
8. Future traffic is forwarded only to the correct segment, reducing network congestion.

# Switches

A switch is a network device used to connect multiple devices in a network. It is also called Switching Hub.

It works at the Data Link Layer (Layer 2) of OSI Model and it use MAC Addresses to send data to required devices.

A switch works smarter than a hub because it sends data only to the required device instead of all devices.

- Connects multiple devices in a LAN
- Forwards data to the correct destination device
- Uses MAC addresses for communication
- Reduces network traffic
- Minimizes data collisions

### Working of Switches

- A device sends a data frame to the switch.
- The switch receives the frame on one of its ports.
- It reads the source MAC address and stores it in its MAC address table.
- The switch checks the destination MAC address in the frame.
- If the destination MAC address exists in the MAC table, the switch forwards the data only to the correct port.
- If the destination MAC address is unknown, the switch broadcasts the frame to all ports except the sender’s port.
- The destination device receives the data and communication takes place successfully.

# VLAN (Virtual Local Area Network)

A VLAN is a way to divide one physical switch into multiple separate virtual networks.

Even though all computers are connected to the same switch, VLAN makes them behave like they are on different networks.


### Working of VLANs

1. The network administrator creates VLANs on a managed switch.
2. Switch ports are assigned to different VLANs.

Example:

- Ports 1–12 → VLAN1
- Ports 13–24 → VLAN2

3. Devices connected to those ports become members of that VLAN.
4. When a device sends data, the switch checks which VLAN the device belongs to.
5. The switch forwards the data only inside that VLAN.
6. Broadcast traffic also stays only inside that VLAN.
7. Devices in the same VLAN can communicate directly.
8. Devices in different VLANs cannot communicate directly.
9. A router or Layer-3 switch is needed for communication between different VLANs


# Features of Switch

## 1. Spanning Tree Protocol (STP)

**STP** prevents network loops when multiple switches are connected together.  
If a loop is detected, STP blocks one port to stop continuous data circulation and keep the network stable.

### Important Point

- Prevents broadcast storms and network failure
- Works at Layer 2

## 2. Trunking

**Trunking** allows multiple VLAN traffic to travel between switches using a single connection called a **trunk port**.

### Important Point

- Carries data for multiple VLANs
- Used between switches

## 3. ISL and 802.1Q

These are **VLAN tagging protocols** used to identify VLAN traffic.

### ISL (Inter-Switch Link)

- Cisco proprietary protocol
- Older VLAN tagging method

### 802.1Q

- IEEE standard VLAN tagging protocol
- Most commonly used today

## 4. Port Mirroring (Port Monitoring)

Port mirroring sends a copy of network traffic from one port to another monitoring port.

### Uses

- Network monitoring
- Packet analysis
- Security analysis using tools like Wireshark

## 5. Port Authentication

Port authentication allows only authorized devices to connect to switch ports using MAC address checking.

### Important Point

- Improves network security
- Unauthorized devices can be blocked automatically

## 6. Content Switch

A content switch improves network performance using features like:

- Load balancing
- Data caching

It distributes network traffic across multiple servers for better performance and reliability.
