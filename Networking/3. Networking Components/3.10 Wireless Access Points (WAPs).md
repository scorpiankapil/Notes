# Wireless Access Points

A Wireless Access Point (WAP) is a network device that allows wireless devices to connect to a wired network using Wi-Fi/radio signals.

It acts as a bridge between wireless device and wired network

- Provides wireless network connectivity
- Connects wireless clients to wired network
- Transmits and receives radio signals
- Allows access to network resources and Internet
- Extends wireless coverage

## Working of Wireless Access Point (WAPs)

- The Wireless Access Point connects to a wired network or router.
- It broadcasts wireless Wi-Fi signals in the surrounding area.
- Wireless devices like laptops and smartphones detect the Wi-Fi signal.
- Devices connect to the access point using the Wi-Fi password.
- The access point transfers data between wireless devices and the wired network/internet.
